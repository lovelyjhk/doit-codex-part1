# 첫째마당 · 코덱스 시작하기

첫째마당은 1~2장입니다. 코덱스의 기본 개념을 익히고, VS Code에서 첫 파일을 만든 뒤 프롬프트·반복 규칙·파일 태그·변경 확인을 연습합니다.

## 이 순서로 시작하세요

1. [첫째마당 작업 규칙](RULES.md)을 읽습니다.
2. [첫째마당 파일 찾기](FILES.md)에서 현재 실습의 시작 자료를 확인합니다.
3. 현재 실습 안내에 따라 빈 연습 폴더를 준비하거나 필요한 시작 자료를 복사합니다. 앞 실습을 이어 하는 단계는 같은 폴더와 파일을 유지합니다.
4. [첫째마당 프롬프트](PROMPTS.md)에서 해당 문장을 입력합니다.
5. 작업을 마친 뒤 [첫째마당 모범 답안](../solutions/README.md#첫째마당)과 비교합니다.
