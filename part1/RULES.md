# 첫째마당 작업 규칙

## 모든 실습에 적용하는 순서

1. 내려받은 저장소와 별도로 `doit-work` 폴더를 만듭니다.
2. 서로 독립된 실습은 `01-prompts`, `02-hello`처럼 다른 연습 폴더에서 진행합니다. 2장의 첫 명령·스레드·파일 태그·diff는 안내에 따라 같은 `02-hello` 폴더와 `hello.py`를 이어서 사용합니다.
3. 안내에서 지정한 시작 파일만 복사합니다. 모범 답안은 작업을 마친 뒤 엽니다.
4. VS Code에서는 저장소 전체가 아니라 현재 연습 폴더를 엽니다.
5. 저장소의 배포 원본은 직접 수정하지 않습니다. 새 연습 폴더로 복사한 작업 사본은 실습 지시에 따라 수정합니다. 새 결과 파일을 요구한 실습은 시작 파일과 다른 이름으로 저장하고, `02-hello`의 스레드·diff 실습은 앞 단계에서 만든 `hello.py`를 이어서 수정합니다.

## 첫째마당에서 기억할 기준

- Python 예제는 Python 3 기본 기능만 사용합니다. `python` 명령이 동작하지 않으면 `py`를 사용합니다.
- `@` 파일 태그 실습에서는 제안 목록에서 파일을 선택했는지 확인합니다.
- diff 화면에서 변경 전후의 파일과 줄을 확인합니다. 수정이 이미 저장된 환경이라면 원하지 않는 변경을 구체적으로 되돌리도록 요청합니다. 적용 전에 제안만 보려면 첫 요청에 아직 파일을 수정하지 말라고 적습니다.
- 날짜·날씨·음악·승인 화면처럼 실행 환경에 따라 달라지는 결과는 직접 확인합니다.
- 파일에 기준 날짜가 적혀 있으면 임의로 오늘 날짜로 바꾸지 않습니다.
- 자료에 없는 이름·수치·일정은 만들지 않고 `[확인 필요]`로 남깁니다.
