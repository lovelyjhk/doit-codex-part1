# [Do it! 실습] 보고서를 PPT 슬라이드로 구성하기

월간 보고서를 발표용 7장 구성표로 줄입니다. 이번 결과물은 발표 내용을 설계하는 Markdown 구성표입니다.

1. 파일 탐색기에서 `doit-work/03-04_slide_outline` 폴더를 새로 만듭니다.
2. 아래 시작 파일을 모두 복사하고, VS Code의 **파일 → 폴더 열기**로 이 폴더를 엽니다.

- [sales_report_2026_04.md](start/sales_report_2026_04.md)

3. [입력할 프롬프트](prompts.md)를 순서대로 Codex에 입력합니다. 파일 이름 앞의 `@`는 입력 자료를 선택하는 파일 태그입니다. 선택이 어렵다면 같은 폴더에 있는 정확한 파일 이름을 적습니다.
4. `slide_outline.md`를 열고 다음 항목을 원본과 비교합니다.

- [ ] 슬라이드 구성표가 정확히 7개입니다.
- [ ] 각 장에 본문 3개와 발표자 노트가 있습니다.
- [ ] 4월 1,970,000원, 전월 대비 -1.5%, 위험 고객 1명을 유지했습니다.
- [ ] 미정 원인·효과·일정이 확인 필요로 남아 있습니다.

5. 부족한 부분은 같은 대화에서 수정 요청을 보냅니다. 파일이 열리지 않으면 복사한 위치와 확장자를 확인합니다. [모범 답안](../../solutions/part2/chapter03/04_slide_outline/README.md)은 결과를 만든 뒤 비교하세요.

앞 실습에서 직접 만든 보고서로 이어서 진행해도 됩니다. 따로 시작하는 독자를 위해 같은 내용의 입력 파일을 제공합니다.
