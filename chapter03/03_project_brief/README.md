# [Do it! 실습] 새 프로젝트 기획서 초안 만들기

기획 메모를 여섯 구성의 문서로 발전시키고, 근거가 없는 시장 수치와 예산을 구분합니다.

1. 파일 탐색기에서 `doit-work/03-03_project_brief` 폴더를 새로 만듭니다.
2. 아래 시작 파일을 모두 복사하고, VS Code의 **파일 → 폴더 열기**로 이 폴더를 엽니다.

- [project_brief_sample.md](start/project_brief_sample.md)

3. [입력할 프롬프트](prompts.md)를 순서대로 Codex에 입력합니다. 파일 이름 앞의 `@`는 입력 자료를 선택하는 파일 태그입니다. 선택이 어렵다면 같은 폴더에 있는 정확한 파일 이름을 적습니다.
4. `project_brief_draft.md`와 인쇄용 PDF를 열고 다음 항목을 원본과 비교합니다.

- [ ] 여섯 구성이 모두 있습니다.
- [ ] PDF는 10쪽 안팎이며 단순 표지만으로 분량을 채우지 않았습니다.
- [ ] 예산과 착수일을 확정하지 않았습니다.
- [ ] 범위에 없는 결제·공개 추천 기능을 포함하지 않았습니다.
- [ ] 기대 효과는 아직 검증하지 않은 가설입니다.

5. 부족한 부분은 같은 대화에서 수정 요청을 보냅니다. 파일이 열리지 않으면 복사한 위치와 확장자를 확인합니다. [모범 답안](../../solutions/part2/chapter03/03_project_brief/README.md)은 결과를 만든 뒤 비교하세요.

모범 답안의 [편집용 Markdown](../../solutions/part2/chapter03/03_project_brief/project_brief_draft.md)과 [10쪽 PDF](../../solutions/part2/chapter03/03_project_brief/project_brief_draft.pdf)를 함께 제공합니다. 여섯 구성은 여러 페이지에 나누어 들어갑니다.
