# 초개인용 숏폼 SNS 기획 메모

학습용 가상 프로젝트입니다. 아래 계획은 확정된 사업 실적이 아닙니다.

- 주제: 본인의 짧은 브이로그를 기록하고 초대한 지인과 공유하는 SNS.
- 문제 가설: 공개 게시가 부담스러운 사용자는 가까운 사람에게만 일상을 공유하고 싶어 할 수 있습니다. 실제 인터뷰는 아직 하지 않았습니다.
- 첫 시험 범위: 짧은 영상 업로드, 초대받은 사람에게 공유, 내 영상 삭제.
- 이번 시험에서 제외: 광고, 결제, 공개 추천 피드, 실시간 방송.
- 일정 제안: 1주차 문제 확인, 2주차 화면 초안, 3주차 시험판, 4주차 사용성 확인. 착수일은 미정입니다.
- 예산: 한도, 인건비, 서버비 모두 미정입니다.
- 기대 효과 가설: 가까운 사람과 부담을 줄여 일상을 기록할 수 있습니다. 효과 수치와 목표 이용자 수는 미정입니다.
- 확인할 사항: 공유 대상 설정, 영상 삭제 범위, 업로드 실패 안내, 모바일 사용성.
- 승인 담당자와 실제 참여자는 아직 정하지 않았습니다.
