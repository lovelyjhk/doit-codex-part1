# [Do it! 실습] 영수증 사진을 경비 정산표로 만들기

영수증 4건이 담긴 이미지를 읽고 통화별 합계를 구합니다. 읽히지 않는 금액과 표시가 없는 세금을 구분합니다.

제공 이미지는 학습용 가상 영수증이며, Codex 실행 화면을 촬영한 캡처가 아닙니다.

1. 파일 탐색기에서 `doit-work/03-07_receipts` 폴더를 새로 만듭니다.
2. 아래 이미지 파일만 복사하고, VS Code의 **파일 → 폴더 열기**로 이 폴더를 엽니다.

- [receipts_sample.png](start/receipts_sample.png)

3. Codex에서 새 대화를 만들고 `receipts_sample.png`를 입력창에 끌어 놓아 첨부합니다. 이미지가 첨부되었는지 확인한 뒤 [입력할 프롬프트](prompts.md)를 입력합니다. 이번 실습에서는 이미지에서 정보를 읽도록 전사본과 모범 답안은 첨부하지 않습니다.
4. `expense_report.md`를 열고 다음 항목을 원본과 비교합니다.

- [ ] KRW 30,500과 USD 12.50을 따로 합산했습니다.
- [ ] KRW의 판독 불가 금액 1건을 합계에서 제외했습니다.
- [ ] 영수증 2·4의 세금과 영수증 2의 결제 수단을 `[확인 필요]`로 남겼습니다.
- [ ] 세금 중복 합산과 임의 환율 변환이 없습니다.

5. 부족한 부분은 같은 대화에서 수정 요청을 보냅니다. 파일이 열리지 않으면 복사한 위치와 확장자를 확인합니다. [모범 답안](../../solutions/part2/chapter03/07_receipts/README.md)은 결과를 만든 뒤 비교하세요.

[receipts_sample.txt](start/receipts_sample.txt)는 결과를 확인할 때 사용하는 대조용 전사본입니다. 이미지가 정상적으로 첨부되지 않으면 파일을 다시 첨부하고 이미지가 보이는지 먼저 확인하세요.
