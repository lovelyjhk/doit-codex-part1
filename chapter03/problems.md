# 3장 마무리 문제

각 문제는 새 `doit-work/03-review-번호` 폴더에서 시작합니다. 필요 파일만 복사한 뒤 VS Code에서 해당 폴더를 엽니다. [입력할 프롬프트](problems/prompts.md)는 문제 조건을 요청하는 예시입니다. 결과 표현보다 수치·근거·확인 필요 표시를 비교하세요.

## 문제 1

- **문제 제목**: 보고서를 임원용 1페이지로 요약하기 ★
- **문제 내용**: 제공된 보고서를 읽고 핵심 내용, 주요 수치, 의사결정이 필요한 사항, 추가로 확인할 내용을 `executive_summary.md`에 1페이지 분량으로 정리하세요. 원문의 수치와 의미를 유지하고 없는 원인이나 성과는 추측하지 마세요. 1분기 합계, 이미 반영한 반품, 제안과 확정 사실의 구분을 확인합니다.
- **필요 파일**: [chapter03/problems/start/presentation_report_sample.md](problems/start/presentation_report_sample.md). 같은 내용의 [12쪽 PDF](problems/start/presentation_report_sample.pdf)는 선택 자료입니다.
- **모범 답안 파일**: [solutions/part2/chapter03/problems/executive_summary_example.md](../solutions/part2/chapter03/problems/executive_summary_example.md)

Markdown의 인쇄 페이지 수는 글꼴·여백에 따라 달라집니다. 한 페이지 조건은 인쇄 미리보기에서 확인하고 길면 핵심 수치를 유지하며 문장을 줄이세요.

## 문제 2

- **문제 제목**: 기획서 초안을 원문과 비교해 검수하기 ★★
- **문제 내용**: 기획 메모와 제공된 기획서 초안을 비교하세요. 원문에 없는 수치나 일정이 확정된 사실처럼 적혀 있는지, 필요한 내용이 빠졌는지 확인합니다. `brief_review.md`에 검토 위치, 확인한 내용, 수정 제안, 수정 이유를 정리하세요. 근거가 없는 값은 [확인 필요]로 남기고 문제가 없는 부분도 확인한 근거를 적으세요. 입력 원문과 검수용 초안은 수정하지 않습니다.
- **필요 파일**: [chapter03/problems/start/project_brief_sample.md](problems/start/project_brief_sample.md), [chapter03/problems/start/project_brief_draft_example.md](problems/start/project_brief_draft_example.md)
- **모범 답안 파일**: [solutions/part2/chapter03/problems/brief_review_example.md](../solutions/part2/chapter03/problems/brief_review_example.md)

## 문제 3

- **문제 제목**: 정해진 양식에 맞춰 기획 메모 정리하기 ★★
- **문제 내용**: 양식과 작성 규칙을 읽고 기획 메모를 양식에 맞춰 채우도록 한 문장으로 요청하세요. `department_filled.md`로 저장한 뒤 같은 입력과 규칙으로 `department_filled_retry.md`를 한 번 더 만듭니다. 제목과 항목 순서가 유지되는지 비교하고 원문에 없는 값은 [확인 필요]로 남기세요. 두 결과의 문장이 완전히 같을 필요는 없습니다.
- **필요 파일**: [chapter03/problems/start/project_brief_sample.md](problems/start/project_brief_sample.md), [chapter03/problems/start/department_template.md](problems/start/department_template.md), [chapter03/problems/start/department_rules.md](problems/start/department_rules.md)
- **모범 답안 파일**: [solutions/part2/chapter03/problems/department_filled_example.md](../solutions/part2/chapter03/problems/department_filled_example.md), [두 번째 결과 예시](../solutions/part2/chapter03/problems/department_filled_retry_example.md)
