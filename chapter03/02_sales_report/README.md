# [Do it! 실습] 매출 데이터로 월간 보고서 쓰기

월별 매출과 고객 위험 표시를 구분해 보고서를 씁니다. 이름이 sales_2026_04.csv인 파일에도 3월 자료가 들어 있으므로 월을 먼저 확인합니다.

1. 파일 탐색기에서 `doit-work/03-02_sales_report` 폴더를 새로 만듭니다.
2. 아래 시작 파일을 모두 복사하고, VS Code의 **파일 → 폴더 열기**로 이 폴더를 엽니다.

- [sales_2026_04.csv](start/sales_2026_04.csv) — 3월과 4월의 가상 매출 4행
- [sales_2026_03.csv](start/sales_2026_03.csv) — 비교용 3월 2행
- [data_description.md](start/data_description.md)

3. [입력할 프롬프트](prompts.md)를 순서대로 Codex에 입력합니다. 파일 이름 앞의 `@`는 입력 자료를 선택하는 파일 태그입니다. 선택이 어렵다면 같은 폴더에 있는 정확한 파일 이름을 적습니다.
4. `sales_report_2026_04.md`를 열고 다음 항목을 원본과 비교합니다.

- [ ] 4월 파일은 4행, 3월 비교 파일은 2행이며 빈 값이 없습니다.
- [ ] 4월은 1,970,000원, 3월은 2,000,000원입니다.
- [ ] 전월 대비 30,000원 감소, 변화율 -1.5%입니다.
- [ ] 4월 위험 높음은 1명, 낮음은 1명, 중간은 0명입니다.
- [ ] 같은 3월 자료를 두 번 합산하지 않았습니다.
- [ ] 감소 원인과 위험 평가 근거는 [확인 필요]입니다.

5. 부족한 부분은 같은 대화에서 수정 요청을 보냅니다. 파일이 열리지 않으면 복사한 위치와 확장자를 확인합니다. [모범 답안](../../solutions/part2/chapter03/02_sales_report/README.md)은 결과를 만든 뒤 비교하세요.

원고의 Risk는 실제 파일의 소문자 `risk` 열을 가리킵니다. 위험 고객은 `높음`으로 표시된 4월 고객입니다. 위험의 원인까지 주어진 것은 아니므로 평가 근거를 추측하지 않습니다.
