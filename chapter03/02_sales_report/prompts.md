# 입력할 프롬프트

## 1. 자료 파악

```text
sales_2026_04.csv와 sales_2026_03.csv의 열 이름과 뜻, 데이터 행 개수, 빈 값이 있는 열을 표로 정리해 주세요. data_description.md를 참고하고 data_overview.md로 저장해 주세요. 두 파일에 같은 3월 자료가 있는지도 확인하고 입력 파일은 수정하지 마세요.
```

## 2. 보고서 작성

```text
너는 업무 데이터 분석가야. sales_2026_04.csv와 sales_2026_03.csv를 읽고 2026년 4월 매출 보고서 초안을 작성해 줘.
4월 파일에는 두 달이 들어 있으므로 month가 2026-04인 행만 4월로 집계해.
3월 비교는 sales_2026_03.csv만 사용하고 같은 3월 자료를 중복 합산하지 마.
핵심 지표는 4월 총매출, 전월 대비 금액과 변화율, 4월 risk 높음인 위험 고객 수로 정리해. 낮음·중간·높음의 고객 수도 구분해.
표보다 문장 요약을 우선하고 계산에 쓴 원본 파일과 행 번호를 밝혀 줘. 첫 줄의 열 이름을 1행으로 세어 줘.
이상치가 있으면 근거와 원본 행 번호를 적고 금액의 크기만으로 오류라고 단정하지 마.
자료에 없는 매출 변화 원인이나 위험 평가 근거는 [확인 필요]로 표시해.
원본을 수정하지 말고 sales_report_2026_04.md로 저장해.
```

## 이어서 수정하기

```text
3월 행을 두 번 더했는지 확인해 주세요. 3월 비교 금액은 sales_2026_03.csv만 사용하고, 두 달의 고객을 섞지 말고 4월 위험 고객 수를 다시 확인해 주세요.
```
