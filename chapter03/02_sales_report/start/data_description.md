# 2026년 3월과 4월 매출 예시

실습용 가상 매출입니다. 실제 회사·고객의 실적이 아닙니다. 원고 화면과 같은 값을 제공합니다.

| 열 | 뜻 |
|---|---|
| month | 매출 월, YYYY-MM |
| customer | 가상 고객 구분, A 또는 B |
| sales | 해당 월의 고객별 매출, 원화(KRW) |
| risk | 미리 부여한 고객 위험 표시, 낮음·중간·높음 |

`sales_2026_04.csv`는 이름과 달리 **3월 2행과 4월 2행, 총 4행**을 포함합니다. 월별로 `month`를 구분해 집계하세요. 한 달에 고객별 한 행이므로 이 자료에서는 행 수와 중복을 제외한 고객 수가 같습니다. 실제 자료에 동일 고객이 여러 행 있으면 고객 수를 중복 계산하지 않아야 합니다.

`sales_2026_03.csv`는 비교 연습을 위해 따로 제공하는 같은 3월 2행입니다. 4월 파일 안의 3월 데이터와 동일하므로 두 파일을 합쳐 3월을 두 번 계산하지 마세요. 4월 파일에서 `2026-04`만 선택하고, 3월 파일에서 `2026-03`을 선택해 비교할 수 있습니다.

위험 고객 수는 4월 `risk`가 `높음`인 고객 수입니다. 4월에는 낮음과 높음이 각각 한 고객이며, 3월에는 낮음과 중간이 각각 한 고객입니다. 위험을 정한 실제 평가 근거나 원인은 제공하지 않았으므로 추측하지 않습니다.

두 파일에는 빈 값이 없습니다. 전월 대비 변화율은 `(4월 매출 - 3월 매출) / 3월 매출 × 100`입니다. CSV 첫 줄의 열 이름을 1행으로 세어 원본 행 번호를 기록합니다. 금액의 크기만으로 이상치나 오류를 단정하지 않습니다.
