# 마무리 문제 프롬프트

## 문제 1

```text
presentation_report_sample.md를 읽고 임원용 1페이지 분량의 executive_summary.md로 요약해 줘. 핵심 수치, 의사결정 요청, 리스크와 확인 필요를 포함하고 확정 사실과 제안을 구분해. 전년 비교·이익·절감 시간은 만들지 말고, 이미 반영한 반품을 다시 빼지 마. 원본은 수정하지 마.
```

## 문제 2

```text
project_brief_sample.md와 project_brief_draft_example.md를 비교해 기획서 초안을 검수해 줘. 원문에 없는 수치·날짜·담당자가 사실처럼 확정되었거나 필요한 항목이 빠졌는지 확인하고, brief_review.md에 검토 위치·확인한 내용·수정 제안·수정 이유로 정리해. 근거 없는 값은 [확인 필요]로 남기고 문제가 없는 부분도 확인한 근거를 적어 줘. 두 입력 파일은 수정하지 마.
```

## 문제 3

```text
department_rules.md와 department_template.md를 기준으로 project_brief_sample.md의 내용만 넣어 department_filled.md를 작성해 줘.
```

다시 요청할 때:

```text
같은 입력과 규칙으로 department_filled_retry.md를 작성하고, 두 결과의 소제목 이름과 순서가 같은지 비교해 줘. 기존 결과는 유지해.
```
