# 외부 공유 전 보안 점검 연습

본문·메모·삭제된 문장·문서 속성의 검토 위치를 별도 Markdown으로 기록합니다. 모든 이름·이메일·토큰·계획·예산은 교육용 가상 값이며 실제 개인정보나 인증 정보가 아닙니다.

1. 새 작업 폴더에 [보고서.docx](start/보고서.docx)만 복사하고 VS Code로 폴더를 엽니다.
2. [프롬프트](prompts.md)를 입력해 `보안_검토.md`를 만듭니다. 원본 Word 파일은 수정하지 않습니다.
3. 결과가 네 문제 유형과 세 상태를 구분하는지, 삭제된 문장과 메모도 확인했는지 살펴봅니다. 검사하지 못한 부분은 `확인 불가`로 남겨야 합니다.
4. 민감한 원문 값이 결과에 복사되지 않았는지 확인한 뒤 [모범 답안](../../../solutions/part2/chapter03/examples/security_review/보안_검토.md)과 비교합니다.

이 체크리스트는 발견 위치를 확인하는 연습입니다. 조직 규정과 실제 공유 승인 여부가 제공되지 않았으므로 전체 문서가 공개 가능하다는 결론을 내리지 않습니다.
