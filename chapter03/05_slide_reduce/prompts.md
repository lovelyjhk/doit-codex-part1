# 입력할 프롬프트

## 1. 원본 확인

```text
@report_2026_q1.pptx를 읽고 핵심 메시지 5줄, 슬라이드별 한 줄 요약,
추가로 확인할 정보를 report_summary.md로 저장해 줘.
원본에 없는 내용은 [확인 필요]로 표시하고 원본 PPTX는 수정하지 마.
PPTX 읽기가 불가능하면 그 이유를 밝히고 ppt_slide_inventory_sample.csv를 대신 읽어 줘.
대체 파일을 사용했다면 결과 첫머리에 사용한 입력 파일을 적어 줘.
```

## 2. 구성 줄이기

```text
위 요약을 바탕으로 10장 발표 자료 구성안을 만들어 줘.
각 장마다 제목, 핵심 메시지 한 줄, 본문 2~3개, 원본 슬라이드 번호를 적어 줘.
원본 30장 모두 본문 또는 부록의 어디로 옮겼는지 대응표를 작성해.
부록으로 옮길 세부 내용도 따로 적어 줘. 제안과 확정 사실을 구분해.
원본에 없는 수치를 넣지 말고 slide_outline_10.md로 저장해.
```

## 이어서 수정하기

```text
빠진 원본 슬라이드 번호를 찾아 본문 또는 부록 대응표에 보완해 주세요. 새 수치는 추가하지 마세요.
```
