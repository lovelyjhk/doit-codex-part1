# [Do it! 실습] 발표 자료 30장을 10장으로 줄이기

실제로 30장이 들어 있는 PPTX를 읽고 내용이 어디로 합쳐졌는지 추적합니다. CSV는 같은 내용을 담은 텍스트 대체 입력입니다.

1. 파일 탐색기에서 `doit-work/03-05_slide_reduce` 폴더를 새로 만듭니다.
2. 아래 시작 파일을 모두 복사하고, VS Code의 **파일 → 폴더 열기**로 이 폴더를 엽니다.

- [report_2026_q1.pptx](start/report_2026_q1.pptx)
- [ppt_slide_inventory_sample.csv](start/ppt_slide_inventory_sample.csv)

3. [입력할 프롬프트](prompts.md)를 순서대로 Codex에 입력합니다. 파일 이름 앞의 `@`는 입력 자료를 선택하는 파일 태그입니다. 선택이 어렵다면 같은 폴더에 있는 정확한 파일 이름을 적습니다.
4. `report_summary.md`와 `slide_outline_10.md`를 열고 다음 항목을 원본과 비교합니다.

- [ ] 원본 슬라이드가 30장입니다.
- [ ] 요약 메시지가 5줄이며 슬라이드별 30줄 요약이 있습니다.
- [ ] 새 구성은 10장이고 원본 30장의 대응이 빠지지 않았습니다.
- [ ] 반품 100만원을 다시 차감하지 않았습니다.
- [ ] 원문에 없는 전년 비교·이익을 만들지 않았습니다.

5. 부족한 부분은 같은 대화에서 수정 요청을 보냅니다. 파일이 열리지 않으면 복사한 위치와 확장자를 확인합니다. [모범 답안](../../solutions/part2/chapter03/05_slide_reduce/README.md)은 결과를 만든 뒤 비교하세요.

PPTX는 PowerPoint 등 지원 프로그램에서 열어 보세요. 이 실습의 완성 기준은 10장 **구성안**입니다. 본문과 부록의 실제 PPT 제작은 다음 작업으로 확장할 수 있습니다.
