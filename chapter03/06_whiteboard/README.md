# [Do it! 실습] 화이트보드 사진을 회의록으로 정리하기

긴 화이트보드 전사본에서 결정 사항, 담당자, 일정, 읽을 수 없는 내용을 1페이지 분량으로 정리합니다. 원고 화면의 ‘첫걸음 클래스 신규 고객 안내 개선’과 같은 교육용 가상 기록입니다.

1. 새 `doit-work/03-06_whiteboard` 폴더를 만들고 [whiteboard_transcript_sample.txt](start/whiteboard_transcript_sample.txt)를 복사합니다. VS Code의 **파일 → 폴더 열기**로 이 폴더를 엽니다.
2. [입력할 프롬프트](prompts.md)를 입력해 `whiteboard_meeting_notes.md`를 만듭니다.
3. 다음 기준으로 원본과 결과를 대조합니다.

- [ ] 회의 일시 2026-09-01 14:00~15:30과 전체 기한 2026-09-04를 유지했습니다.
- [ ] 질문 10개와 답변 초안·내부 검토 기록이라는 결정 사항을 보존했습니다.
- [ ] 김담당·박상담·이기획·최운영의 가상 역할과 9/2~9/4 중간 일정을 맞췄습니다.
- [ ] 예정 작업을 완료 실적이나 고객 공개 승인으로 바꾸지 않았습니다.
- [ ] 외부 공개 담당, 후속 점검 날짜, 검토 대상 수, 기존 메모의 판독 불가 표현을 원문대로 [확인 필요]에 남겼습니다.
- [ ] 결정 사항·담당자·일정·[확인 필요]가 구분되고 글씨와 표기가 읽힙니다.

4. 부족한 항목은 같은 대화에서 수정 요청을 보냅니다. [모범 답안](../../solutions/part2/chapter03/06_whiteboard/whiteboard_meeting_notes.md)과 비교하되 문장 표현보다 사실과 미정 상태를 확인하세요.

Markdown 인쇄 페이지 수는 글꼴·여백에 따라 달라집니다. 한 페이지가 넘으면 이름·날짜·판독 불가 메모를 보존한 채 반복 설명을 줄이세요. 전사본 속 회의와 사람은 모두 가상이며 실제 회사·고객의 기록이 아닙니다.
