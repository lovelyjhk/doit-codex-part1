# 입력할 프롬프트

```text
너는 회의 기록 정리 도우미야. @whiteboard_transcript_sample.txt에서 읽을 수 있는 내용만 사용해 1페이지 분량의 회의록 초안을 만들어 줘.
결정 사항, 담당자, 일정, [확인 필요]로 나누어 정리해.
원본의 이름·날짜와 가상 표기를 보존하고 예정 업무를 완료한 일로 바꾸지 마.
읽을 수 없는 글자·날짜·숫자는 추측하지 말고 판독 불가 메모를 원문 그대로 [확인 필요]에 남겨 줘.
내부 공유 검토와 고객 공개 승인을 구분하고, 보류된 작업을 확정하지 마.
원본은 수정하지 말고 whiteboard_meeting_notes.md로 저장해.
```

## 이어서 수정하기

```text
담당자 항목에서 원본에 없는 이름이나 추측으로 채운 날짜가 있는지 확인해 주세요. 읽을 수 없었던 메모는 원문 그대로 [확인 필요]로 되돌리고 내부 공유 검토를 고객 공개 승인으로 쓴 부분이 있으면 고쳐 주세요.
```
