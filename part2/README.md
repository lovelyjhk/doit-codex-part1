# 둘째마당 · 업무에 코덱스 활용하기

둘째마당은 3~6장입니다. 문서·파일·반복 업무·데이터·엑셀을 다루고, 자신의 직군에서 자동화할 일을 고르는 방법을 연습합니다.

## 이 순서로 시작하세요

1. [둘째마당 작업 규칙](RULES.md)을 읽습니다.
2. [둘째마당 파일 찾기](FILES.md)에서 현재 실습의 시작 자료를 확인합니다.
3. 현재 단계에 필요한 입력 파일을 준비합니다. 앞 결과나 같은 스킬을 이어 쓰는 단계는 해당 실습 안내를 따릅니다.
4. [둘째마당 프롬프트](PROMPTS.md)에서 해당 문장을 입력합니다.
5. 작업을 마친 뒤 [둘째마당 모범 답안](../solutions/part2/README.md)과 비교합니다.
