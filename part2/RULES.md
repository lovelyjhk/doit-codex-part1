# 둘째마당 작업 규칙

## 모든 실습에 적용하는 순서

1. 각 실습 안내의 ‘필요 파일’ 경로에서 지정한 자료를 연습 위치에 준비합니다. 입력 위치는 `start`, `inputs`, `problem_start` 또는 장 폴더일 수 있습니다.
2. 새 실습은 별도 폴더에서 시작합니다. 앞 결과나 같은 스킬을 이어 쓰는 단계는 해당 안내에 따라 같은 작업 폴더를 유지합니다.
3. 시작 자료, 작업 결과, 모범 답안을 서로 구분합니다.
4. 원본과 이전 결과는 덮어쓰지 않습니다.
5. 프롬프트의 입력 파일·출력 파일·금지 행동·확인 기준을 먼저 읽습니다.
6. 결과의 이름·날짜·수치·빈 값을 원본과 대조한 뒤 모범 답안을 엽니다.

## 둘째마당에서 기억할 기준

- 파일에 적힌 기준 날짜를 사용합니다. 프롬프트가 오늘 날짜를 요구한 경우에만 실행일을 확인합니다.
- 빈 값과 기록 없는 지역은 임의로 0으로 채우지 않습니다.
- 자료에 없는 이름·수치·일정·판단은 `[확인 필요]`로 남깁니다.
- 예제 코드는 메일을 자동 발송하지 않습니다. 4장의 선택적 수동 시험은 본인 주소 한 건만 해당 실습 안내에 따라 진행합니다. 거래처 발송, 계약 승인, 발주, 출하, 일정 변경은 수행하지 않습니다.
- 문서·스프레드시트 결과는 내용뿐 아니라 페이지, 시트, 수식, 차트와 잘림도 확인합니다.
- 패키지가 필요한 예제는 해당 README의 `requirements.txt` 또는 설치 안내만 따릅니다.

## 4장 실행 위치 예외

3·5·6장은 새 개별 연습 폴더를 VS Code에서 엽니다. 4장의 파일 처리·메일 예제 코드는 경로를 안전하게 제한하므로 저장소 최상위를 열고 `work/ch04-xx`에 시작 자료의 복사본을 준비합니다. 명령도 저장소 최상위 터미널에서 실행합니다.

4장의 스킬 만들기는 `meeting_skill_practice`를 저장소 밖의 새 연습 위치에 복사하고, 재사용 실습은 같은 폴더와 스킬을 유지합니다. 마무리 문제는 별도의 `moonlight_skill_practice` 폴더에서 진행합니다. 어떤 실습에서도 원본 보관 폴더를 직접 이름 변경하거나 분류하지 않습니다.
