# 공식 출처 근거표 만들기

1. `AGENTS.md`와 사용자가 지정한 확인 메모를 먼저 읽습니다.
2. 검색 결과의 요약문이 아니라 공식 상세 페이지에서 직접 확인한 값만 `source_log.csv`에 기록합니다.
3. 출처 URL, 자료 기준일, 화면 확인일을 서로 다른 항목으로 적습니다.
4. 결과표를 만든 뒤 각 행을 원문과 다시 대조합니다.
5. 원문에서 확인하지 못한 값은 추정하지 않고 `확인 필요`로 표시합니다.
6. 특정 지역, 제품명, 날짜를 이 스킬에 고정하지 않습니다.
7. 인증 키와 개인정보를 스킬, 프롬프트, 결과 파일에 넣지 않습니다.
