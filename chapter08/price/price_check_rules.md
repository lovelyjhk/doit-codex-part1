# 직구 가격 비교 규칙

1. 모델 번호, 색상, 구성품, 새 제품 여부가 같아야 같은 후보로 비교합니다.
2. 상품가만 비교하지 않습니다.
3. 예상 총액은 상품가, 현지 배송비, 국제 배송비, 대행 수수료, 예상 세금을 합칩니다.
4. 미확인 비용은 0으로 계산하지 않고 `[가격 확인 필요]`로 표시합니다.
5. 판매처 URL과 확인 날짜·시간, 적용 환율을 남깁니다.
6. 반품 비용, 국내 A/S, 전압·규격을 가격과 따로 비교합니다.
7. 결과는 ‘확인 시점 기준 예상액’이라고 쓰고 현재 최저가로 단정하지 않습니다.
8. 자동 주문·로그인·결제는 하지 않습니다.
