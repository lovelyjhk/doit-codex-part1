# 저자 경력 사실 메모

이 파일은 저자가 직접 작성합니다. 공개 폴더에는 주소, 전화번호, 이메일, 생년월일과 증명서 번호를 넣지 않습니다.

## 지원 목표

- 지원 직무:
- 지원 이유:
- 제출 마감:

## 경력 사실

### 경력 1

- 기간:
- 조직·프로젝트:
- 맡은 역할:
- 내가 직접 한 행동:
- 사용한 도구:
- 확인 가능한 결과:
- 근거 파일 또는 증명 방법:
- 아직 확인하지 못한 내용:

## 교육·자격

- 이름:
- 기관:

- 확인 방법:
