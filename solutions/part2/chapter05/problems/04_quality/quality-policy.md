# 결측치·이상치 처리 기준

출처: 학습용 가상 데이터 `quality_sales.csv`, 규칙: `quality-rules.md`입니다.

| 후보 | 데이터 행 | 개수 | 처리 |
|---|---|---:|---|
| 매출 결측 | 2행 Q002 | 1행 | 빈 값을 보존하고 원천 금액 확인 |
| 지역 결측 | 3행 Q003 | 1행 | 지역을 추정하지 않고 확인 요청 |
| 음수 매출 | 4행 Q004, -2,000원 | 1행 | 반품·취소 여부 확인 전 유지 |
| 큰 매출 | 5행 Q005, 800,000원 | 1행 | 실습 기준 100,000원 초과. 정상 대량 거래인지 확인 |
| 중복 ID | 1행·7행 Q001 | 2행, 추가 중복 1행 | 두 행 모두 표시하고 유지 |

`quality_flagged.csv`에는 원본 7행·4열을 보존하고 flags 열만 추가했습니다. 데이터 행 번호는 머리글을 제외합니다. 후보는 자동 표시했지만 값은 자동으로 고치지 않았습니다.

원본 기준 매출은 빈 매출을 제외한 6행 합계 853,000원입니다. 음수와 중복 후보를 포함했습니다. 평균은 853,000 ÷ 6 = 142,166.67원입니다. 이를 확정 실적으로 사용하지 않습니다. 지역과 금액 확인, 반품 확인, 중복 여부 확인 뒤 승인된 규칙에 따라 별도 정제본을 만들 수 있습니다.
