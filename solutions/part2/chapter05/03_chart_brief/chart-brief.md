# 그래프 설계 카드

학습용 가상 데이터 `sales.csv`와 `data-profile.md`를 기준으로 작성한 초안입니다.

| 후보 | 답할 질문 | 종류 | 가로축 / 세로축 | 단위·집계 | 오해 가능성 | 사람의 확인 기준 |
|---|---|---|---|---|---|---|
| 월별 추이 | 월별 매출은 어떻게 바뀌었나요? | 선 | 월 / 매출 | 원, 월별 sales 합계 | 누적 매출로 오해할 수 있음 | 12개월을 빠짐없이 오름차순 표시하고 1월·12월 합계 대조 |
| 품목·채널 비교 | 어떤 카테고리의 매출이 큰가요? | 가로 막대 | 매출 / 카테고리 | 원, 연간 카테고리별 sales 합계 | 판매 수량과 매출의 순위가 다를 수 있음 | 같은 기간 사용, 매출 축을 0에서 시작 |
| 비율 비교 | 카테고리별 매출 비중은 얼마인가요? | 도넛 | 해당 없음 / 해당 없음 | %, 카테고리 매출 ÷ 연간 총매출 | 면적만으로 작은 차이 비교가 어려움 | 분모와 합계가 맞고 반올림 차이 설명 |

목표 자료가 없어 목표 달성률은 만들지 않습니다. 브라우저 실습에서는 첫 번째 후보인 월별 추이를 선택합니다. 빈 값과 제외 행이 없는 현재 원본 48행을 모두 사용합니다.
