# 모범 답안: 엑셀 보고서

[sales_report_2026.xlsx](sales_report_2026.xlsx)를 내려받아 Excel에서 여세요. 요약·데이터·차트 세 시트가 있습니다. 요약의 월별 매출과 카테고리별 매출은 데이터 시트를 참조하는 SUMIF 수식입니다. 차트도 그 요약 셀을 참조합니다.

1. 요약의 1월 59,000원, 12월 103,000원, 합계 972,000원을 원본과 대조하세요.
2. 데이터 시트는 원본의 48행·7열입니다. 매출은 숫자로 저장되어 있고 머리글에 필터가 있습니다.
3. 복사한 XLSX에서만 매출 한 칸을 바꾸고 요약·차트가 함께 갱신되는지 확인한 뒤 저장하지 않고 닫으세요.

원본 행을 추가하면 표와 수식 범위도 확장해야 합니다. 전년·목표 자료가 없어 비교 수치를 만들지 않았습니다.
