# 엑셀 상품별 차트 검수표

학습용 가상 자료에 대한 참고 답안입니다. `inputs/sales_sample.csv` 6행과 `inputs/july_sales_chart_review.xlsx`를 대조했습니다. 원본 CSV와 엑셀 보고서는 수정하지 않았습니다.

| 항목 | 파일에서 확인한 내용 | 남은 확인 |
|---|---|---|
| 제목 | 상품별 차트 제목은 2026년 6·7월 상품별 매출 비교 | 실제 Excel 화면의 제목 표시 |
| 축·단위 | 가로축 상품, 세로축 매출액(원). 묶은 세로 막대형의 금액 축 시작값은 0 | Excel에서 축·눈금·한글이 읽히는지 확인 필요 |
| 기간·범례 | 상품별 비교는 2026년 6월과 7월, 두 계열로 구분 | Excel에서 범례 표시 확인 필요 |
| 빈 값·자료 | CSV 6행의 값과 데이터 시트 6행이 일치하며 빈 값과 중복 행 없음 | 원본을 바꾸면 다시 대조 |
| 집계 기준 | 상품별 6·7월 revenue_krw 합계. 5월 2행은 데이터 시트와 월별 차트에 보존하며 상품별 6·7월 비교에서는 제외 | 실제 업무의 제외 기준은 별도 확인 |
| 전체 행 | 상품 A·B만 막대 차트에 들어가며 전체 행은 포함하지 않음 | Excel 화면의 두 상품 표시 확인 필요 |
| 계산 근거 1 | 6월 전체: A 4,050,000 + B 3,680,000 = 7,730,000원 | 사람이 CSV에서 다시 합산 |
| 계산 근거 2 | 7월 전체: A 3,840,000 + B 4,200,000 = 8,040,000원 | 사람이 CSV에서 다시 합산 |
| 계산 근거 3 | 전체 증감: 8,040,000 - 7,730,000 = +310,000원 | 사람이 다시 계산 |
| 상품별 증감 | A: 3,840,000 - 4,050,000 = -210,000원. B: 4,200,000 - 3,680,000 = +520,000원. 두 증감액의 합은 +310,000원 | A의 음수 기호와 감소 색이 읽히는지 Excel에서 확인 필요 |
| 전체 증감률 | 310,000 ÷ 7,730,000 × 100 = 약 +4.0%. 상품별 증감률의 단순 평균을 쓰지 않음 | 없음 |

참고 답안 검증에서는 저장된 XLSX의 수식·계산값과 편집 가능한 차트 2개(월별 꺾은선형·상품별 묶은 세로 막대형)를 확인했습니다. 차트 원본 구조에서 상품 A·B, 6·7월 계열, 금액 축 시작값 0을 확인했고 저장 파일을 다시 읽은 미리 보기에서도 제목·축·범례와 두 차트 배치를 확인했습니다. 이는 Excel 데스크톱 앱의 실제 조작 검증이 아니므로, Excel에서의 글자 표시·겹침·차트 편집 가능 여부는 확인 필요로 남깁니다.
