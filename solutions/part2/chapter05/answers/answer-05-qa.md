# 그래프 확인표

학습용 가상 데이터에 대한 확인 예시입니다. 파일 내용과 집계는 확인했으며, 사용 환경에서의 브라우저 표시는 독자가 확인합니다.

| 항목 | 확인 내용 | 남은 확인 |
|---|---|---|
| 제목 | 2026년 월별 매출 추이: 월별 변화라는 질문과 일치 | 없음 |
| 축 | 가로축 월, 세로축 매출(원), 매출축 0~120,000 | 브라우저 확대 시 글자 표시 |
| 기간·단위 | 2026년 1~12월, 원 | 없음 |
| 빈값·제외 | 48행 모두 포함, 빈 값·중복·제외 없음 | 원본을 바꾸면 다시 확인 |
| 집계 | month별 sales 합계. 누적 값 아님 | 없음 |
| 원본 대조 1 | 1월: 11,000+13,500+16,000+18,500 = 59,000원 | 사람이 CSV 첫 4행을 다시 합산 |
| 원본 대조 2 | 12월: 22,000+24,500+27,000+29,500 = 103,000원 | 사람이 CSV 마지막 4행을 다시 합산 |
| 원본 대조 3 | 12개월 합계 = 972,000원 | 사람이 월별 표의 합계를 다시 합산 |

차트와 CSV는 수정하지 않았습니다. HTML의 숫자는 고정되어 있으므로 CSV 변경 후 새로 만들어야 합니다.
