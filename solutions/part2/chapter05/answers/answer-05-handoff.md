# 엑셀 상품별 차트 인계 메모

- 확인한 내용: CSV 6행과 엑셀 데이터 시트가 일치합니다. 6월 매출은 7,730,000원, 7월은 8,040,000원이며 전체 증감액은 +310,000원, 증감률은 약 +4.0%입니다. 상품 A -210,000원과 B +520,000원의 합이 전체 증감액과 같습니다.
- 차트 확인 근거: 저장된 파일의 수식·계산값·네이티브 차트 구조와 미리 보기를 대조했습니다. 상품별 차트는 상품 A·B와 6·7월 두 계열을 사용하며 금액 축은 0부터 시작합니다. 전체 행은 막대 차트에서 제외했습니다.
- 남은 질문: 실제 Excel에서 제목·축·범례·한글이 읽히고 두 차트가 겹치지 않나요? A의 감소 표시와 차트 편집이 정상인가요? Excel 앱에서 직접 확인하지 않았으므로 확인 필요입니다.
- 다음 확인자·기한: 지정되지 않았습니다. 임의의 이름이나 기한을 적지 않습니다.
- 다음 행동: 원본 CSV에서 6월·7월 매출과 증감액을 다시 계산한 뒤 XLSX를 Excel에서 열어 남은 항목을 확인하고 검수표에 결과를 적습니다. 현재는 CSV와 XLSX를 수정하지 않으며 문제를 발견하면 위치와 수정 요청부터 정리합니다.
