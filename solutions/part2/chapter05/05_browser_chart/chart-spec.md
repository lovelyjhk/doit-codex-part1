# 월별 매출 그래프 설명

- 파일: `sales-chart.html`, 오프라인 HTML·SVG 그래프
- 원본: `sales.csv` / 학습용 가상 데이터 / 2026년 1~12월
- 질문: 월별 매출은 어떻게 바뀌었나요?
- 제목: 2026년 월별 매출 추이
- 가로축: 월, 1~12월 오름차순 / 세로축: 매출(원), 0부터 120,000까지
- 집계: `month`별 `sales` 합계, 48행 모두 포함. 누적 매출이 아닙니다.
- 빈 값·중복: 원본에서 발견되지 않았으며 임의 보정이나 제외는 하지 않았습니다.
- 연 합계: 972,000원, 1월: 59,000원, 12월: 103,000원
- HTML 안의 숫자는 생성 시점에 담은 값입니다. CSV를 수정하면 그래프도 다시 생성해야 합니다.
- 원본 숫자 표를 HTML 하단에 함께 제공하며 외부 스크립트·폰트·네트워크 요청을 사용하지 않습니다.
