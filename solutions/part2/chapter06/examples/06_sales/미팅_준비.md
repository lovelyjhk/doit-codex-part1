# 거래처A 미팅 준비

## 회사와 담당자

- 사업: 독립 서점용 문구 상품 판매, 상품 12종, 재고 확인 주 1회
- 규모·최근 경영 변화: [확인 필요]
- 담당자A 역할: 발주 수량 취합. 계약 결정 권한은 [확인 필요]
- 출처: `거래처_자료.md`의 연습용 내부 메모. 공개 자료는 제공되지 않았습니다.

## 제안 초안 3개

1. 상품 안내표 초안을 함께 검토합니다.
2. 소량 샘플 신청 절차를 안내합니다. 비용은 [확인 필요]입니다.
3. 주간 재고 확인용 표 양식을 검토합니다.

## 예상 질문과 답변 초안

실제로 받은 질문이 아니라 미팅 준비를 위한 예상입니다.

| 예상 질문 | 답변 초안 |
|---|---|
| 어떤 상품이 있나요? | 제공 가능한 상품 안내표 초안을 설명드리겠습니다. 개별 사양은 [확인 필요]입니다. |
| 샘플을 신청할 수 있나요? | 소량 샘플 신청 절차를 안내할 수 있습니다. 비용은 [확인 필요]입니다. |
| 가격은 얼마인가요? | 가격은 아직 확정되지 않아 [확인 필요]입니다. |
| 언제 받을 수 있나요? | 납기는 [확인 필요]입니다. |
| 재고는 어떻게 확인하나요? | 주간 확인에 활용할 표 양식을 검토할 수 있습니다. 운영 방식은 협의가 필요합니다. |

## 진행 순서 제안

| 소요 시간 | 내용 |
|---|---|
| 5분 | 참석자 역할과 요청 사항 확인 |
| 10분 | 상품 안내표 검토 |
| 5분 | 샘플 신청 절차와 미확정 비용 확인 |
| 5분 | 재고 표 양식 검토 |
| 5분 | 확인할 조건과 다음 조치 정리 |

합계 30분입니다. 미팅 날짜, 가격, 비용, 납기, 계약 조건은 [확인 필요]입니다.
