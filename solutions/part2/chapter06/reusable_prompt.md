# 반복 사용 프롬프트 템플릿

대괄호 부분을 실제 파일명과 확인 항목으로 바꾼 후 입력합니다. 입력 파일은 `@` 목록에서 실제 파일로 선택하세요.

```text
너는 반복 업무 자료 정리 도우미야.
@[입력 파일]만 읽고 [결과 파일]을 새로 만들어 줘.
업무명, 마감일, 우선순위, 확인할 항목을 마크다운 표로 정리해 줘.
[확인 항목]을 원문과 대조하고 자료에 없는 내용은 [확인 필요]로 남겨 줘.
입력의 업무를 빠짐없이 포함하고 원본 파일은 수정하지 마.
실제 업무 실행이나 외부 발송은 하지 마.
같은 이름의 결과 파일이 이미 있으면 덮어쓰지 말고 새 파일명을 먼저 확인해 줘.
```

- [결과 파일]: weekly_tasks_summary_retry.md
- [확인 항목]: 업무 다섯 개 포함 여부, 원문에 없는 마감일·우선순위의 확인 필요 표시
