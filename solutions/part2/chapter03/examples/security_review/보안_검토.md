# 보안 검토 체크리스트

검토 대상은 교육용 `보고서.docx`입니다. 본문, 검토 메모, 변경 내용 추적의 삭제문, 문서 속성을 읽었습니다. 입력 파일은 수정하지 않았으며 발견한 이름·연락처·인증 표식·내부 계획의 원문 값을 이 기록에 복사하지 않았습니다.

## 유형별 상태

- [ ] 개인 식별 정보 — **확인 필요**: 본문 담당자·연락처와 문서 속성의 작성자·수정자·연락처 항목을 확인했습니다.
- [ ] 계정·시스템 접근 정보 — **확인 필요**: 본문의 비작동 인증 표식과 변경 기록에 남은 이전 표식을 확인했습니다. 가상 값임이 명시되어 있지만 기록을 점검하는 연습 대상으로 남깁니다.
- [ ] 회사 내부 정보 — **확인 필요**: 내부 검토용 계획·예산과 미정 공유 승인 문장이 있습니다.
- [ ] 메모·변경 기록의 민감 정보 — **확인 필요**: 메모의 담당자·연락처와 삭제문 안의 표식을 확인했습니다.

## 위치별 기록

| 문서 내 위치 | 문제 유형 | 확인이 필요한 이유 | 수정 제안 |
|---|---|---|---|
| 본문 3번째 문단 | 개인 식별 정보 | 담당자와 연락처 형식의 가상 값이 있습니다. | 공유 목적에 필요한지 사람이 확인하고 불필요하면 공유용 복사본에서 가립니다. |
| 본문 4번째 문단 | 접근 정보 | 비작동 인증 표식이 있습니다. | 실제 문서에서 작동하는 키가 들어가지 않았는지 확인하고 공유용 복사본에서는 제거합니다. |
| 본문 5번째 문단 | 내부 정보 | 공개 시점과 예산 성격의 정보가 있고 공유 승인이 미정입니다. | 공개 가능 범위와 승인 담당자를 확인합니다. |
| 본문 6번째 문단에 연결된 검토 메모 | 메모의 개인 식별 정보 | 메모에도 별도 담당자·연락처가 있습니다. | 공유용 복사본의 메모를 검토하고 불필요한 정보를 제거합니다. |
| 본문 7번째 문단의 변경 내용 추적 삭제문 | 변경 기록의 접근 정보 | 화면에서 지워진 것처럼 보여도 삭제된 문장이 파일 안에 남아 있습니다. | 변경 내용을 승인할 담당자가 기록 보존 정책을 확인하고 공유용 복사본의 삭제 이력을 처리합니다. |
| 문서 속성의 작성자·마지막 수정자·설명 | 문서 속성의 개인 식별 정보 | 본문 밖 속성에도 이름·연락처 형식의 가상 값이 있습니다. | 공개용 메타데이터로 정리할지 확인합니다. |

## 검토 범위와 남은 확인

- **검토 범위 내 미발견**: 읽은 본문·메모·삭제문·문서 속성에서 실주소, 실제 고객 명단, 실제 계약서는 발견하지 못했습니다. 이는 해당 문서의 읽은 범위에 대한 결과입니다.
- **확인 불가**: 제공되지 않은 회사 보안·개인정보·저작권 규정, 실제 외부 공유 승인, 별도 시스템이나 이전 파일 버전의 정보는 검사하지 못했습니다.
- DOCX 내부 텍스트를 확인한 결과이며 숨은 이미지의 문자 판독이나 조직 전체 보안 검사를 수행했다는 의미는 아닙니다. 외부 공유 가능 여부는 **[조직 규정 확인 필요]**입니다.

AI 작업: 제공 문서의 항목 분류와 검토 기록 초안 작성. 사람의 남은 작업: 규정 확인, 실제 공유 범위 결정, 공유용 복사본 수정과 최종 승인.
