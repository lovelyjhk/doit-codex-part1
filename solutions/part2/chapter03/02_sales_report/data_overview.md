# 자료 파악 결과

학습용 가상 자료입니다. 열 이름 1행을 제외하면 `sales_2026_04.csv`는 4행(3월 2행·4월 2행), `sales_2026_03.csv`는 2행(3월)입니다. 두 파일에 같은 3월 2행이 들어 있습니다.

| 열 | 뜻 | 4월 파일 빈 값 | 3월 파일 빈 값 |
|---|---|---:|---:|
| month | 매출 월 | 0 | 0 |
| customer | 가상 고객 구분 | 0 | 0 |
| sales | 고객별 해당 월 매출, KRW | 0 | 0 |
| risk | 사전에 부여한 위험 표시 | 0 | 0 |

4월 파일의 4~5행만 4월 합계에 사용합니다. 3월 파일의 2~3행으로 전월 합계를 구합니다. 같은 3월 행을 합쳐 중복 합산하지 않습니다. 위험 고객 수는 4월 `risk`가 `높음`인 서로 다른 고객 수입니다. 이 자료에는 같은 월의 중복 고객이 없습니다.
