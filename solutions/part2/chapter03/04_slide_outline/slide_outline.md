# 4월 매출 보고 7장 구성표

가상 보고서의 구성 예시입니다. 시각화 열은 제작 아이디어입니다.

| 장 | 제목 | 핵심 메시지 | 본문 3개 | 시각화 아이디어 |
|---|---|---|---|---|
| 1 | 문제 제기 | 매출 감소의 근거 확인 | 전월보다 3만원 감소<br>변화 원인은 확인 필요<br>고객 위험의 근거도 확인 | 매출과 확인 항목 표시 |
| 2 | 현황 | 4월 매출은 197만원 | 3월은 200만원<br>전월 대비 1.5% 감소<br>위험 높음 고객은 1명 | 두 달 매출 막대그래프 |
| 3 | 원인 | 감소 원인은 확인 필요 | A는 15만원 증가<br>B는 18만원 감소<br>위험 원인은 별도 확인 | 고객별 증감 비교 |
| 4 | 해결 전략 | 자료의 근거부터 확인 | 위험 평가 기준 확인<br>매출 변화의 근거 확인<br>후속 담당자와 기한 확인 | 세 가지 확인 목록 |
| 5 | 자동화 흐름 | 구현 방식은 확인 필요 | 계산 근거는 원본 CSV<br>매출은 월별로 구분<br>3월 자료 중복 합산 방지 | 입력과 월별 결과 관계 |

| 7 | 실행 계획 | 담당자와 기한 확인 필요 | 평가 기준 추가 확인<br>매출 변화 근거 확인<br>근거 받은 뒤 해석 보완 | 확인 후 보완 순서 |

## 발표자 노트

### 1장

전월과 비교한 감소는 계산으로 확인했지만 원인까지 확인한 것은 아닙니다.

### 2장

4월은 1,970,000원이고 3월은 2,000,000원입니다. 변화율은 -1.5%입니다. 4월 위험 높음은 B 1명, 낮음은 A 1명이며 중간은 0명입니다.

### 3장

A의 150,000원 증가와 B의 180,000원 감소를 합하면 30,000원 감소입니다. B의 위험 표시 변화와 매출 감소의 인과관계는 단정하지 않습니다.

### 4장

확인할 내용은 보고서의 마지막 항목에 근거합니다. 원문에 없는 책임자와 완료일을 지정하지 않습니다.

### 5장

원문에는 자동화 구현 계획이 없습니다. 실제 시스템처럼 묘사하지 않으며 자료의 월 구분과 중복 합산 방지 원칙만 표시합니다.

### 6장

원문에 없는 시간 절감이나 매출 개선 수치를 넣지 않습니다. 기대 효과는 추가 자료가 필요한 항목입니다.

### 7장

담당자와 기한이 미정이므로 [확인 필요]입니다. 평가 기준과 매출 변화 근거를 확인한 뒤 해석을 보완합니다.
