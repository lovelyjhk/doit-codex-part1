# PNG 이름 변경 모범 답안

실행일이 한국 날짜 **2026-09-06**일 때의 예시입니다. 독자의 실행일이 다르면 날짜 부분도 달라집니다. 실제 촬영일을 뜻하지 않습니다.

| 현재 파일명 | 변경할 파일명 | 적용 날짜 |
|---|---|---|
| 1f600.png | photo_20260906_001.png | 2026-09-06 |
| 1f603.png | photo_20260906_002.png | 2026-09-06 |
| 1f604.png | photo_20260906_003.png | 2026-09-06 |
| 1f60a.png | photo_20260906_004.png | 2026-09-06 |
| 1f680.png | photo_20260906_005.png | 2026-09-06 |

변경 5개, 다른 파일 변경 0개가 정상입니다. [실행 코드](../file_ops.py)의 `plan png`로 표를 만든 뒤 검토하고, `apply`에 `--confirm APPLY`를 붙여 승인합니다. `image_sources.txt`는 변경 대상에서 제외합니다.

검증에서는 별도 복사본으로 계획·승인 없는 적용 차단·승인 적용·복구를 실행하고, PNG 다섯 개와 출처 파일의 변경 전후 SHA-256을 비교했습니다. 이 표는 모범 예시이며 Codex 화면 캡처가 아닙니다.
