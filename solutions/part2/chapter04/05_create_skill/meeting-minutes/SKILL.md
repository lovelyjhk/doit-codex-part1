# 회의록 정리

사용자가 지정한 회의 메모 한 개를 읽어 `회의록_정리본.md`와 `확인_목록.md`를 만듭니다. 출력 위치는 사용자가 정한 새 폴더를 사용합니다.

1. 회의일과 주제를 적고, 확정된 결정과 제안·보류를 구분합니다.
2. 할 일은 `할 일 | 담당 | 기한 | 근거` 표로 정리합니다. 근거는 원문 문장이나 짧은 인용으로 표시합니다.
3. 명시되지 않은 담당이나 날짜를 추정하지 말고 `[확인 필요]`로 표시합니다. `다음 회의 전` 같은 상대 표현은 원문 그대로 적고, 날짜가 없으면 확인 목록에 남깁니다.
4. 확인 목록에는 미정 값, 결정되지 않은 제안, 구체화할 내용을 짧게 적습니다.
5. 출력 전에 원문과 대조해 결정·담당·기한을 점검하고 만든 두 파일을 안내합니다.

원본은 덮어쓰지 않습니다. 실제 개인정보·계정 정보는 결과물에 옮기지 않고 해당 부분의 제외 사실만 남깁니다. 외부 전송과 메일 발송은 하지 않습니다. 같은 이름의 출력이 있으면 새 출력 폴더를 사용합니다.
