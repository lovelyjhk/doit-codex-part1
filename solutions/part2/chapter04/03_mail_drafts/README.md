# 모범 답안 거래처 안내 초안

[drafts](drafts/)에 거래처 20곳의 완료 예제를 제공합니다. [생성 코드](make_drafts.py)는 원본 CSV를 읽고 새 출력 폴더에만 기록합니다. `example.com` 이외의 주소는 이 연습 코드에서 거절합니다.

- 회사명·이름·직함은 입력값과 같습니다. 호칭 `님`일 때에는 `가상담당01님`, `사장님`일 때에는 `가상담당02 사장님`처럼 연결합니다.
- 실적은 자료집 2종과 설명회 1회, 다음 일정은 2026년 10월 7일입니다.
- 미정인 회신 마감일·첨부 파일·최종 승인자는 `[확인 필요]`입니다.
- 초안은 파일입니다. 발송 여부를 ‘발송 완료’로 표시하지 않습니다.
