# 모범 답안 다운로드 폴더 정리

`set_sample_dates.py`를 실행한 복사본, 기준일 `2026-09-05`의 결과입니다.

| 원래 이름 | 이동 위치 또는 처리 | 이유 |
|---|---|---|
| 안내.pdf | pdf/안내.pdf | PDF |
| 분류연습_회의록.docx | docx/분류연습_회의록.docx | Word |
| 매출.xlsx | xlsx/매출.xlsx | Excel |
| 이미지.jpg | 이미지/이미지.jpg | 이미지 |
| 메모.txt | 기타/메모.txt | 기타 |
| 오래된_기록.txt | _archive/오래된_기록.txt | 2025-08-01 수정 |
| 경계일_자료.txt | _archive/경계일_자료.txt | 2025-09-05 수정 |
| 작업중.tmp | 원래 위치에 보류 | 임시 파일 |
| ~$잠금파일.txt | 원래 위치에 보류 | 잠금 파일 이름 |

정상 결과는 이동 7개, 보류 2개, 삭제 0개입니다. 기본 코드는 폴더 바로 아래 파일만 처리하고 하위 폴더를 다시 분류하지 않습니다.
