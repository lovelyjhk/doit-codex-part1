# 모범 답안 시험 발송 준비

[example](example/)에서 미리보기, `.eml`, 드라이런 로그를 확인합니다. 받는 사람은 가상 주소 `me@example.com` 한 개입니다. 참조·숨은 참조·첨부 파일은 없습니다.

정상 로그의 `sent: false`는 실제 발송하지 않았다는 뜻입니다. 파일이 생성됐다고 메일이 발송된 것은 아닙니다. 실제 본인 주소 시험 결과는 실행자의 메일 서비스에서 확인하므로 완료 예제에 꾸며 넣지 않습니다.
