# 책방 소개글 번역

입력은 사용자가 지정한 한국어 소개글과 영문 표기 기준입니다. 지정한 새 출력 폴더에 `책방_영문번역.md`와 `번역_확인목록.md`를 저장합니다.

1. 표기 기준의 이름·말투·날짜 형식을 읽고 원문을 문단별로 번역합니다.
2. `한국어 원문 | 영어 번역` 표로 나란히 적습니다. 원문의 사실·수치·확정 여부를 보존하며 원문에 없는 설정이나 홍보 문구를 추가하지 않습니다.
3. 원문의 `[확인 필요]`를 그대로 유지합니다. 새로운 불명확한 항목도 확인 목록에 남깁니다.
4. 이름·날짜·수치·단위와 빠진 문단이 없는지 대조하고 결과를 파일로만 저장합니다. 게시·외부 전송을 하지 않습니다.
5. 입력과 기존 결과를 덮어쓰지 않습니다. 특정 문장이나 날짜를 스킬에 고정하지 않습니다.
