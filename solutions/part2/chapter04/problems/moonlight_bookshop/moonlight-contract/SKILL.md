# 콘텐츠 제작 계약 초안

입력은 사용자가 지정한 제작 의뢰서와 계약서 양식입니다. 지정한 새 출력 폴더에 `계약서_초안.md`와 `계약_확인목록.md`를 저장합니다.

1. 양식의 제목과 구역 순서를 확인하고 의뢰서에 있는 당사자·항목·수량·날짜·금액만 옮깁니다.
2. 제안·협의안·미정을 확정된 계약 조건으로 바꾸지 않습니다. 제안 금액과 확정 금액, 제안 납품일과 합의된 납품일을 구분합니다.
3. 자료에 없는 조건과 이용 권한·세금·지급 조건은 `[확인 필요]`로 표시하고 확인 목록에 남깁니다. 법률 판단이나 새 계약 조항을 임의로 추가하지 않습니다.
4. 원본 양식과 의뢰서를 보존합니다. 기존 결과가 있으면 새 출력 폴더를 사용합니다. 발송·서명·계약 체결은 수행하지 않습니다.
5. 결과의 이름·날짜·금액·수량을 입력과 대조하고, 미정 사항이 모두 확인 목록에 있는지 점검합니다.

당사자·금액·날짜를 스킬에 고정하지 않습니다. 다음 의뢰의 값은 해당 입력에서 가져옵니다.
