# 콘텐츠 견적 검토

입력은 사용자가 지정한 제작 의뢰서와 견적서입니다. 지정한 새 출력 폴더의 `견적서_검토.md`에 결과를 저장합니다.

1. 각 파일의 작성일·업체·통화를 확인하고 요청 항목·수량·형식·기한을 견적과 비교합니다.
2. 수량×단가를 항목별로 검산하고 합계를 별도로 계산합니다. 원본 표시 금액과 재계산 금액, 차이를 구분해 기록합니다.
3. 누락 항목, 일정 차이, 부가세·추가 비용·수정 범위처럼 판단하기 어려운 조건은 `[확인 필요]`로 남깁니다. 입력에 없는 비용을 0원으로 간주하지 않습니다.
4. 결과를 `검토 항목 | 문제 내용 | 확인 요청` 표로 정리합니다. 맞는 항목도 확인되었다고 적고, 원본 견적서를 수정하지 않습니다.
5. 견적 승인·발주·외부 발송을 하지 않습니다. 기존 결과는 보존하고, 계산과 근거를 다시 대조한 뒤 완료합니다.

업체명·단가·수량·합계·날짜는 스킬에 고정하지 않습니다.
