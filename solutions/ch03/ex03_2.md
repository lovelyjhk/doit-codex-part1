# 2장 1번 모범 답안

입력 파일은 [ch03/ex03_2.md](../../ch03/ex03_2.md)입니다. 아래 코드 블록 안이 **5줄 요약 예시**입니다.

```text
이 프로젝트는 파이썬 인사말 프로그램으로 Codex의 파일 생성·후속 수정·참고 자료 지정·변경 검토와 승인 방식을 익히는 것이 목적입니다.
먼저 ex03_2.md를 읽고 프로젝트 목적과 실습 순서를 확인합니다.
다음으로 새 스레드에서 이 파일을 @ 파일 태그로 지정해 목적과 순서를 5줄로 요약합니다.
이어서 별도의 새 스레드에서 태그 없이 같은 요청을 하고 근거와 누락된 내용을 비교합니다.
마지막으로 ex03_3 문제에서 승인 방식별 자동 처리와 사용자 확인의 차이를 정리합니다.
```

태그를 사용하면 참고 대상으로 선택한 파일이 분명해집니다. 태그 없이도 Codex가 파일을 찾아 같은 답을 낼 수 있으므로 결과 차이는 직접 관찰합니다. 속도나 토큰 감소는 이 문제의 정답 조건이 아닙니다.
