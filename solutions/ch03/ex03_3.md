# 2장 2번 모범 답안

아래는 개념 비교입니다. 독자 PC에서 실행한 관찰 결과를 대신하지 않습니다.

| 비교 항목 | 이해할 점 |
|---|---|
| 승인 요청 | 허용된 범위 안의 작업은 자동으로 진행될 수 있습니다. 승인이 필요한 작업은 사용자에게 확인을 요청합니다. |
| 나 대신 승인 | 제공되는 환경에서는 승인이 필요한 일부 요청을 자동 검토합니다. 모든 작업을 무조건 승인하거나 작업 가능 범위를 없애는 기능은 아닙니다. |
| 전체 권한 | 작업 가능한 범위가 넓어집니다. 실제 승인 요청 여부는 함께 적용되는 정책과 설정을 확인해야 합니다. |

작업 가능한 범위는 어느 파일과 네트워크에 접근할 수 있는지를 정합니다. 승인 정책은 그 작업을 실행하기 전에 언제 확인을 받아야 하는지를 정합니다.

이 문제의 작은 파일 생성은 허용된 작업 폴더 안에서 이루어지므로 여러 방식에서 똑같이 자동 처리될 수 있습니다. 그 경우 관찰표에 “승인 창이 나타나지 않았고 파일이 생성됨”처럼 실제 결과를 적습니다. 차이를 만들려고 위험한 작업을 추가할 필요는 없습니다.

메뉴를 선택할 수 없거나 설명만 읽었다면 “미지원” 또는 “설명 비교”라고 기록하는 것이 올바른 답입니다.
