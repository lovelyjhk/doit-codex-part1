# 실행 전 검토 모범 답안

| 계획 | 대상과 변경 | 외부 접근 | 되돌리기 | 위험도 | 먼저 확인할 일 |
|---|---|---|---|---|---|
| A | 현재 연습 폴더의 파일 이름·크기 읽기 | 없음 | 변경 없음 | 낮음 | 현재 폴더가 연습 폴더인지 확인합니다. |
| B | notice.md 새로 생성 | 없음 | 새로 만든 파일만 제거할 수 있음 | 중간 | 파일이 이미 있는지 확인하고 있으면 멈춥니다. |
| C | 다운로드 폴더 전체 파일 삭제 | 없음 | 백업 여부 확인 필요 | 높음 | 대상 목록·백업·목적·승인 확인 전에는 진행하지 않습니다. |
| D | 고객 명단 외부 업로드 | 있음 | 전송 후 완전한 회수 보장 어려움 | 높음 | 수신자·전송 권한·정보 범위 확인 전에는 진행하지 않습니다. |

분류는 이 예제의 조건에 대한 판단입니다. 요청은 검토뿐이므로 어떤 계획도 실행하지 않습니다.
