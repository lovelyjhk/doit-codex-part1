# 달빛책방 메모리 실습 모범 확인 기준

정답은 특정 날씨나 특정 노래가 아닙니다. 새 스레드에 짧은 오픈 요청만 입력했을 때 아래 요소가 이어지는지 확인합니다.

- 가게: 달빛책방, 서울 종로구 인사동, 카페를 겸한 책방.
- 말투: 다정한 존댓말.
- 순서: 오늘 날씨 확인 → 어울리는 유튜브 음악 한 개 → 선택 이유 → 직접 만든 따뜻한 문장.
- 끝 문구: “오늘도 좋은 문장 만나세요.”
- 실제 확인: 날씨 출처와 날짜, 유효한 영상 링크, 재생 성공 여부.

메모리가 가게 정보를 떠올렸더라도 검색·브라우저 기능이 없으면 날씨 확인이나 음악 재생은 완료되지 않을 수 있습니다. 반대로 안내문을 읽어 같은 답을 만들었다면 메모리 회상만의 결과라고 판단할 수 없습니다.

다음은 **따뜻한 문장 부분만의 창작 예시**입니다. 실제 메모리 실행 로그가 아닙니다.

> 잠시 쉬어 가시는 이 시간이 한 페이지의 여유로 남았으면 좋겠습니다. 오늘도 좋은 문장 만나세요.

날씨와 유튜브 URL을 고정 답안으로 넣지 않았습니다. 매번 실제 출처를 확인해야 합니다.
