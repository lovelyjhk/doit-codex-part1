# 1장 3번 모범 답안

문서 정리 작업에 적용할 규칙 5줄입니다. [AGENTS.example.md](AGENTS.example.md)를 별도 문서 작업 폴더에 복사한 뒤 `AGENTS.md`로 바꿔 사용할 수 있습니다.

```markdown
- 원본은 덮어쓰지 않고 수정본은 날짜와 버전을 붙인 새 파일로 저장합니다.
- 요청받은 작업 폴더 안의 지정 파일만 다룹니다.
- 본문은 존댓말로 작성하고 요청하지 않은 내용과 구조는 바꾸지 않습니다.
- 확인되지 않은 사실은 [확인 필요]로 표시하고 민감한 정보는 결과에 포함하지 않습니다.
- 완료 후 변경 내용과 원본 대조 결과를 함께 알려 줍니다.
```

이 규칙은 문서 원본을 보존하는 상황의 예입니다. 실제로 파일을 직접 수정해야 하는 프로젝트에서는 그 작업에 맞게 규칙을 조정합니다.
