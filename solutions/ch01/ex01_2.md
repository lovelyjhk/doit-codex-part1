# 1장 2번 모범 답안

문서 요약 템플릿을 선택한 예입니다.

```text
너는 문서 요약 도우미야.
@[입력 파일]만 읽고 [독자]를 위한 [출력 파일]을 새로 만들어 줘.
목적, 핵심 내용, 결정 필요 사항 순서로 [줄 수]줄 이내로 작성해 줘.
원문에 없는 사실은 만들지 말고 모호한 내용은 [확인 필요]로 적어 줘.
원본을 수정하지 마. 완료 후 이름·숫자를 원문과 대조한 결과를 알려 줘.
```

입력 파일은 `document.md`, 독자는 `새로 합류한 팀장`, 출력 파일은 `summary.md`, 줄 수는 `10`으로 바꿔 사용할 수 있습니다.

```text
너는 문서 요약 도우미야.
@document.md만 읽고 새로 합류한 팀장을 위한 summary.md를 새로 만들어 줘.
목적, 핵심 내용, 결정 필요 사항 순서로 10줄 이내로 작성해 줘.
원문에 없는 사실은 만들지 말고 모호한 내용은 [확인 필요]로 적어 줘.
원본을 수정하지 마. 완료 후 이름·숫자를 원문과 대조한 결과를 알려 줘.
```
