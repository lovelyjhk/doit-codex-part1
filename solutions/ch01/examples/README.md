# 1장 예시 결과

제공한 가상 입력 자료만으로 만든 모범 결과입니다. AI가 실제로 생성한 실행 로그는 아닙니다.

- [교정된 보고서](report_edited.md): 오탈자와 띄어쓰기만 수정했습니다.
- [문서 요약](summary.md): 원문의 핵심과 미정 사항을 정리했습니다.
- [월별 매출 요약](sales_summary.md): 빈 금액 한 건을 누락으로 남겼습니다.
- [회의록 정리](meeting_summary.md): 결정 사항과 담당 업무를 구분했습니다.
- [단계별 발표 구성안](slides_outline.md): 원문 내용으로 주제와 순서를 정했습니다.
- [CSV 합계 코드](sum_sales.py)와 [입력 CSV](sales_2026.csv): 원고의 파일 읽기·실행 예시를 CSV로 연습합니다.

합계 답안을 직접 실행하려면 `sum_sales.py`와 `sales_2026.csv`를 같은 연습 폴더로 복사하고 그 폴더의 터미널에서 `python sum_sales.py`를 실행합니다. 확인된 금액 550,000원과 누락 1건이 출력됩니다.
