# 1장 1번 모범 답안

아래는 예시 자료를 복사한 작업 폴더에서 사용할 수 있는 답안입니다. 문장이 완전히 같을 필요는 없지만 입력·출력·제약·완료 기준이 분명해야 합니다.

## 1 보고서 다듬기

```text
@report.md를 읽고 보고받는 팀장이 이해하기 쉬운 존댓말로 다듬어 report_edited.md로 저장해 줘.
맞춤법과 어색한 문장만 수정하고, 원문의 뜻·제목·이름·숫자는 유지해 줘.
원본과 다른 파일은 수정하지 마.
수정 후 이름과 숫자를 원문과 대조하고 바꾼 표현을 알려 줘.
```

## 2 문서 요약하기

```text
@document.md만 읽고 처음 참여하는 팀장을 위한 summary.md를 만들어 줘.
목적, 핵심 내용, 결정 필요 사항으로 나누어 10줄 이내로 작성해 줘.
원문에 없는 사실을 만들거나 원본을 수정하지 마. 미정 사항은 [확인 필요]로 표시해 줘.
이름과 숫자가 원문과 일치하는지 확인하고 결과 파일명을 알려 줘.
```

## 3 데이터 분석하기

```text
@sales_2026.csv의 월별 확인된 매출 합계와 누락 건수를 sales_summary.md의 표로 정리해 줘.
amount의 단위는 원이고, 빈 금액을 0으로 확정하거나 추정하지 마.
원본은 수정하지 마. 월별 합계의 합과 전체 확인된 금액 합계가 일치하는지 검증해 줘.
누락으로 인해 확정할 수 없는 월은 [확인 필요]로 적어 줘.
```
