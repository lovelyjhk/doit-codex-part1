# 출판 업로드 사전점검

원고와 표지의 출판 준비 상태를 점검하고, 사람이 최종 게시 여부를 결정할 수 있는 기록을 만든다.

## 작업 순서

1. `AGENTS.md`와 출판 대상 폴더의 `CONTEXT.md`를 먼저 읽는다.
2. 원고 파일, 표지 파일, 메타데이터, 권리·라이선스 기록, AI 사용 기록의 경로를 확인한다.
3. 원고의 판형·여백·페이지 수·글꼴 포함·이미지 해상도를 확인한다.
4. 표지의 제목·저자명·재단선·책등·바코드 영역과 300dpi 여부를 확인한다.
5. 본문·표지·홍보 이미지에 생성형 AI를 사용했다면 플랫폼의 현재 질문과 표시 기준을 공식 화면에서 다시 확인하고 사실대로 기록한다.
6. KDP는 `https://kdp.amazon.com/en_US/bookshelf`, 교보문고는 `https://partner.kyobobook.co.kr/`에서 로그인 후 업로드 화면을 연다.
7. 파일 선택과 미리보기 검수까지만 진행한다. 게시, 판매 신청, 가격 확정, 외부 전송은 사용자의 별도 승인이 없으면 실행하지 않는다.
8. 화면 캡처에는 계정명, 이메일, 주소, 세금 정보, 결제 정보, ISBN 미공개값을 노출하지 않는다.
9. `author_publish_log.md`에 확인 시각, 파일 해시, 미리보기 결과, 남은 오류, 사람이 결정할 항목을 기록한다.

## 완료 조건

- 원고와 표지 파일이 각각 하나로 확정되어 있다.
- 파일 해시와 확인 시각이 기록되어 있다.
- 권리·라이선스와 생성형 AI 사용 여부가 빈칸 없이 기록되어 있다.
- 미리보기 오류가 없거나, 남은 오류와 수정 담당자가 적혀 있다.
- 실제 게시 버튼은 누르지 않았다.
