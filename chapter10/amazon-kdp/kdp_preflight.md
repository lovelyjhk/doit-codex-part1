# Amazon KDP 발행 전 점검표

## 파일과 도서 정보

- [ ] 원고 파일을 별도 보관했습니다.
- [ ] 제목·부제·저자명이 원고와 등록 정보에서 같습니다.
- [ ] 목차와 링크를 확인했습니다.
- [ ] 표지의 제목과 저자명이 정확합니다.
- [ ] 본문·표지·이미지·인용의 권리를 확인했습니다.

## AI 사용과 저자 기록

- [ ] `ai_use_log.md`를 저자가 직접 작성했습니다.
- [ ] KDP 최신 콘텐츠 지침을 확인했습니다.
- [ ] 생성 콘텐츠와 보조적 이용을 사실대로 구분했습니다.
- [ ] 초안, 저자 수정본, 변경 기록을 분리해 보관했습니다.

## KDP 화면 — 저자 직접 수행

- [ ] 계정·세금·지급 정보를 직접 확인했습니다.
- [ ] 도서 정보 화면을 직접 입력했습니다.
- [ ] 원고와 표지를 직접 업로드했습니다.
- [ ] 온라인 미리보기에서 모든 장을 확인했습니다.
- [ ] 권리와 가격을 직접 확인했습니다.
- [ ] 최종 발행 버튼을 직접 눌렀습니다.

민감한 계정·세금·계좌·주소·신분 정보 화면은 캡처하지 않습니다.
