# 6장 내 직군에서 시작하기

출판 준비용 초안입니다. 내 업무에서 반복되는 정리·비교·초안 작성을 고르고, 결과를 사람이 확인할 기준을 세웁니다. 아래의 가상 자료로 먼저 연습한 뒤 자신이 사용할 권한이 있는 자료에 적용하세요.

## 시작하기

1. 아래에서 실습이나 관심 있는 예시 하나를 선택합니다.
2. 각 안내의 `start` 안에 있는 파일만 새 작업 폴더로 복사합니다. 원본 자료와 모범 답안을 분리하고 VS Code에서 새 폴더를 엽니다.
3. 프롬프트의 `@` 입력에서 파일을 선택하고 결과를 요청합니다. Markdown은 VS Code에서 읽을 수 있는 문서이며 CSV는 첫 줄이 열 이름인 표 데이터입니다. 이 장에서는 별도 프로그램 설치나 코드 실행이 필요하지 않습니다.
4. 결과를 입력 자료와 대조한 뒤 모범 답안과 비교합니다. 표의 수치·날짜·누락 표시가 같아야 하며 문장 표현은 달라도 됩니다.

## 자료를 읽는 기준

- 날짜가 있는 예시는 파일에 적힌 **기준일**을 사용합니다. 실행한 오늘 날짜로 바꾸지 않습니다.
- CSV 근거 행은 머리글이 1행이며 첫 데이터가 2행입니다.
- 빈 값은 0이나 사실로 채우지 않습니다. 원문에 없는 정보는 `[확인 필요]`로 표시합니다.
- 회사·담당자·금액은 모두 가상 자료입니다. 모범 답안은 실제 업무의 법률·회계·인사 판단이 아닙니다.
- 메일·게시·발주·출하·일정 변경은 초안 검토 후 사람이 결정합니다.
