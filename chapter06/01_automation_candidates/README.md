# [Do it! 실습] 코덱스를 활용해 자동화할 업무 판단하기

06-1의 실습입니다. 반복 업무 5개에서 맡길 범위를 정하고, 사람이 확인해야 할 일과 중단 조건을 구분합니다.

1. PC에 새 작업 폴더를 만듭니다. [업무_목록.md](start/업무_목록.md)를 복사하고 VS Code의 **파일 → 폴더 열기**로 그 폴더를 여세요.
2. 업무 목록의 입력 자료, 확인할 사실과 최종 결정을 읽습니다. 정확한 반복 횟수처럼 주어지지 않은 값은 추측하지 않습니다. 자신의 자료를 쓰려면 이 파일의 표만 바꾸고 실제 개인정보를 넣지 않습니다.
3. 아래 프롬프트를 입력하고 `@` 파일 목록에서 실제 `업무_목록.md`를 선택합니다.

```text
너는 업무 자동화 후보를 정리하는 도우미야.
@업무_목록.md의 반복 업무 5개를 반복성, 규칙성, 검수 가능성 기준으로 표로 정리해 자동화_후보표.md를 만들어 줘.
후보마다 입력 자료, 맡길 범위, 확인 기준, 중단 조건을 적어 줘.
원본 변경, 대외 발송, 결제·계약·인사 판단은 맡기지 말고 사람이 확인할 일로 표시해 줘.
판단이 어려운 부분은 [확인 필요]로 남기고 근거 없는 시간 절감 수치는 만들지 마.
중단 조건을 먼저 검토한 뒤 가장 먼저 작게 시험할 후보 하나와 선정 이유, 시험 범위, 완료 기준을 적어 줘.
이번에는 목록의 업무 자체를 실행하지 말고 후보표 파일만 만들어 줘. 원본 파일은 수정하지 마.
```

4. 생성된 `자동화_후보표.md`에서 **중단 조건**을 먼저 읽습니다. 비어 있거나 확인할 수 없는 결과를 그대로 쓰라고 했다면 중단 조건을 구체적으로 적어 달라고 요청하세요.
5. 후보 5개가 모두 있는지, 원본 변경과 실제 발송이 사람의 결정으로 남았는지 확인합니다. [모범 결과](../../solutions/part2/chapter06/01_automation_candidates/README.md)와 비교하세요.

## 확인할 점

- [ ] 반복성·규칙성·검수 가능성이 업무 목록에 근거합니다.
- [ ] 각 후보에 맡길 범위·확인 기준·중단 조건이 있습니다.
- [ ] 먼저 시험할 후보 하나와 작은 시험 범위·완료 기준이 있습니다.
- [ ] 가격·납기·공유·일정 변경은 사람이 결정합니다.
