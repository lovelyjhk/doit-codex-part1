# 답변 정책 — 연습용 가상 정책
- 견적: 문의 수량과 제품 조건을 확인한 뒤 영업 담당자가 검토합니다. 가격과 할인은 제공되지 않았습니다.
- 주문: 사용자가 서비스의 주문 내역 화면에서 상태를 확인하도록 안내합니다. 이 샘플에는 주문 조회 데이터가 없습니다.
- 환불: 담당자가 정책과 주문 상태를 확인한 뒤 가능 여부를 안내합니다. 자동 확정하지 않습니다.
- 기술 문의: 오류 코드를 기술 담당자에게 전달할 검토 항목으로 정리합니다. 제공된 해결 절차는 없습니다.
- 불만: 불편에 공감하고 안내 차이를 담당자 검토 항목으로 남깁니다. 보상이나 처리 기한은 약속하지 않습니다.
- 애매한 문의는 확인 필요로 분류합니다. 샘플 답변에서 개인정보를 요청하지 않습니다.
