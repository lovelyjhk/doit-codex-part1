# 고객지원: 문의 분류와 답변 프롬프트

`start` 안의 파일을 새 작업 폴더로 복사하고 그 폴더를 VS Code에서 여세요. `@` 뒤에서 실제 파일을 선택한 뒤 입력합니다.

```text
너는 고객 문의 답변 초안 도우미야.
@문의_목록.csv와 @답변_정책.md만 읽고 문의_답변초안.md를 만들어 줘.
문의 유형을 견적, 주문, 환불, 기술 문의, 불만으로 분류하고 애매한 것은 [확인 필요]로 남겨 줘.
각 문의의 답변은 공감 인사, 확인된 사실, 다음 절차 순서로 쓰고 유형별 건수와 사람이 검수할 건을 적어 줘.
정책에 없는 약속·환불 확정·개인정보 요청은 하지 마. 실제 발송과 원본 수정은 하지 마.
```
