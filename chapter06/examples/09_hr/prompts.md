# 인사: 채용 공고 초안 프롬프트

`start` 안의 파일을 새 작업 폴더로 복사하고 그 폴더를 VS Code에서 여세요. `@` 뒤에서 실제 파일을 선택한 뒤 입력합니다.

```text
너는 채용 공고 초안 도우미야.
@채용_조건.md만 읽고 채용_공고초안.md를 만들어 줘.
구성은 담당 업무 → 자격 요건 → 우대 사항 → 근무 조건 → 지원 방법으로 해 줘.
성별·나이·출신 학교 조건을 추가하지 말고 자료에 없는 조건은 [확인 필요]로 표시해 줘.
지원자 평가나 채용 판단, 실제 게시를 하지 말고 원본은 수정하지 마.
```
