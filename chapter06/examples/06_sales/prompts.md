# 영업: 미팅 준비 프롬프트

`start` 안의 파일을 새 작업 폴더로 복사하고 그 폴더를 VS Code에서 여세요. `@` 뒤에서 실제 파일을 선택한 뒤 입력합니다.

```text
너는 영업 담당자를 돕는 미팅 준비 도우미야.
@거래처_자료.md만 읽고 거래처A의 미팅_준비.md를 만들어 줘.
1. 회사 개요: 사업, 규모, 최근 변화와 출처 구분
2. 담당자의 역할: 확인되는 범위만
3. 우리가 제안할 수 있는 방안 3개
4. 예상 질문 5개와 답변 초안
5. 30분 미팅 진행 순서
확인할 수 없는 내용은 [확인 필요]로 표시하고 예상 질문은 실제 질문으로 쓰지 마.
웹 검색·원본 수정·대외 발송은 하지 마.
```
