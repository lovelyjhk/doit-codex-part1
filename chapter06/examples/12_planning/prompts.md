# 기획: 기획서 초안 프롬프트

`start` 안의 파일을 새 작업 폴더로 복사하고 그 폴더를 VS Code에서 여세요. `@` 뒤에서 실제 파일을 선택한 뒤 입력합니다.

```text
너는 기획서 초안 도우미야.
@기획_자료.md만 읽고 사내 자료 검색 개선을 주제로 기획서_초안.md를 만들어 줘.
배경과 문제 정의 → 현황 분석 → 해결 전략 → 기대 효과 → 일정과 예산 → 리스크와 대응으로 구성해 줘.
각 항목의 첫 줄에 핵심 메시지를 적고 제공되지 않은 숫자·사실은 [확인 필요]로 남겨 줘.
새 전략은 제안으로 표시하고 효과를 측정된 사실처럼 쓰지 마.
마지막에 추가로 채워야 할 정보를 적고 원본 파일은 수정하지 마.
```
