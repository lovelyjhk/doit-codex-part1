# 생산: 일일 실적 보고

06-5 구매·물류·생산의 참고용 예시입니다. 생산 분모와 비교 기간을 확인하고 수치를 검산합니다. 모든 회사·업무·수치·일정은 연습용 가상 자료이며 실제 업무의 규정이나 계약 조건이 아닙니다.

## 따라 하기

1. PC에 새 작업 폴더를 만들고 아래 입력 파일을 모두 복사합니다. VS Code의 **파일 → 폴더 열기**로 그 작업 폴더를 여세요.
2. 입력 자료를 열어 항목의 뜻과 빈칸을 확인합니다. 아래 [프롬프트](prompts.md)를 복사해 Codex에 입력합니다. `@` 파일 후보 목록에서 해당 파일을 선택하세요.
3. 작업 폴더에 만들어진 `일일_생산보고.md`을 열어 아래 기준으로 원문과 대조합니다.
4. 누락이나 임의로 만든 내용이 있으면 “입력 파일의 근거를 다시 확인하고, 근거 없는 내용은 [확인 필요]로 고쳐 줘.”라고 요청합니다. 맞으면 [모범 결과](../../../solutions/part2/chapter06/examples/17_production/README.md)와 비교합니다.

## 입력 파일

- [생산실적.csv](start/생산실적.csv)

## 확인할 점

- [ ] 계획 230·실적 170·불량 5·가중 불량률 2.94%가 맞습니다.
- [ ] 실적 0의 불량률은 0%로 쓰지 않고 %p와 %를 구분합니다.
- [ ] 전일 C 자료 누락을 표시하고 이슈 원인을 추정하지 않습니다.

모범 결과는 가능한 답안의 한 예입니다. 문장 표현이 달라도 근거와 확인 기준이 같으면 됩니다. 원본 수정이나 실제 발송·발주·선정은 이 예시에 포함되지 않습니다.
