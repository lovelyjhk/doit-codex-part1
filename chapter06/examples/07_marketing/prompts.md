# 마케팅: 콘텐츠 캘린더 프롬프트

`start` 안의 파일을 새 작업 폴더로 복사하고 그 폴더를 VS Code에서 여세요. `@` 뒤에서 실제 파일을 선택한 뒤 입력합니다.

```text
너는 콘텐츠 기획 도우미야.
@콘텐츠_조건.md만 읽고 다음 달 콘텐츠_캘린더.md를 만들어 줘.
조건 파일의 기준일과 요일을 사용하고 게시물마다 날짜, 채널, 주제, 카피 초안, 이미지 아이디어, 해시태그 5개를 마크다운 표로 적어 줘.
제공되지 않은 행사·할인·판매 수치를 만들지 말고 필요한 정보는 [확인 필요]로 표시해 줘.
실제 게시나 예약은 하지 말고 원본은 수정하지 마.
```
