# 마케팅: 콘텐츠 캘린더

06-2 영업·마케팅·고객지원의 참고용 예시입니다. 기준 월과 요일이 명시된 조건으로 실제 날짜가 맞는 표를 만듭니다. 모든 회사·업무·수치·일정은 연습용 가상 자료이며 실제 업무의 규정이나 계약 조건이 아닙니다.

## 따라 하기

1. PC에 새 작업 폴더를 만들고 아래 입력 파일을 모두 복사합니다. VS Code의 **파일 → 폴더 열기**로 그 작업 폴더를 여세요.
2. 입력 자료를 열어 항목의 뜻과 빈칸을 확인합니다. 아래 [프롬프트](prompts.md)를 복사해 Codex에 입력합니다. `@` 파일 후보 목록에서 해당 파일을 선택하세요.
3. 작업 폴더에 만들어진 `콘텐츠_캘린더.md`을 열어 아래 기준으로 원문과 대조합니다.
4. 누락이나 임의로 만든 내용이 있으면 “입력 파일의 근거를 다시 확인하고, 근거 없는 내용은 [확인 필요]로 고쳐 줘.”라고 요청합니다. 맞으면 [모범 결과](../../../solutions/part2/chapter06/examples/07_marketing/README.md)와 비교합니다.

## 입력 파일

- [콘텐츠_조건.md](start/콘텐츠_조건.md)

## 확인할 점

- [ ] 10월 화요일 4회와 금요일 5회, 합계 9건입니다.
- [ ] 게시물마다 해시태그가 5개이고 미제공 행사나 할인 약속이 없습니다.

모범 결과는 가능한 답안의 한 예입니다. 문장 표현이 달라도 근거와 확인 기준이 같으면 됩니다. 원본 수정이나 실제 발송·발주·선정은 이 예시에 포함되지 않습니다.
