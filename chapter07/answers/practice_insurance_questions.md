# 7장 마무리 문제 2 질문 목록 모범 답안

근거: `../insurance/sample_policy.txt`, `practice_insurance_summary.md`.

1. 각 담보에 대기기간이 있나요? 있다면 해당 약관 조항과 적용 시작일을 확인할 수 있나요?
2. 각 담보에 감액기간이 있나요? 있다면 기간과 감액 비율이 적힌 약관 조항은 어디인가요?
3. 이 계약의 수익자는 누구이며 어느 서류에서 확인하나요?
4. 생활배상책임 특약의 갱신 주기와 갱신 시 조건은 어디에서 확인하나요?
5. 각 담보의 면책사항이 적힌 약관 조항을 안내받을 수 있나요?

질문 목록은 약관 확인을 돕는 자료이며 보장이나 보험금 지급 여부에 대한 답변이 아닙니다.
