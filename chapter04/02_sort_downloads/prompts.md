# 복사해서 사용할 프롬프트

## 미리 보기

```text
너는 파일 정리 도우미야. work/ch04-02/downloads 바로 아래의 파일만 분류해 줘.
기준일은 연습용 고정 날짜 2026-09-05로 해 줘.
PDF는 pdf, Word는 docx, Excel은 xlsx, jpg/jpeg/png/gif/webp는 이미지, 나머지는 기타 폴더로 옮기는 계획을 작성해 줘.
단, 수정일이 2025-09-05이거나 그 이전이면 종류보다 우선하여 _archive로 옮겨 줘.
.tmp 파일과 ~$로 시작하는 파일은 이동·삭제하지 말고 삭제 후보(보류) 목록에만 적어 줘.
기존 하위 폴더는 탐색하지 말고, 같은 이름이 이미 있으면 덮어쓰지 말고 보류해 줘.
기존 경로·이동 경로·수정일·이유를 표로 보여 줘. 승인 전에는 파일을 옮기지 마.
되돌리기 기록을 남길 수 있게 준비해 줘.
```

## 적용 요청

```text
표를 확인했어. work/ch04-02/downloads의 승인한 이동만 진행해 줘.
삭제 후보는 그대로 두고, 이동 전후 경로를 work/ch04-02/sort_receipt.json에 저장해 줘.
목록을 만든 뒤 파일이 달라졌다면 중단하고 알려 줘.
```
