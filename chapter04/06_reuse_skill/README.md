# [Do it! 실습] 저장한 스킬을 다음 회의록에 그대로 써 보기

앞 실습에서 만든 `meeting_skill_practice` 폴더와 `meeting-minutes` 스킬을 이어서 사용합니다. 두 번째 원문은 이미 `회의02` 폴더에 있습니다. [개별 시작 자료](start/회의록_원문.md)도 같은 내용입니다.

1. 두 번째 원문을 읽고 회의일 2026-09-02, 기획팀, 매주 수요일을 확인합니다. 다음 회의 날짜는 미정이며 작성 기한은 ‘다음 회의 전’입니다.
2. 새 대화에서 같은 스킬을 선택하고 [프롬프트](prompts.md)로 두 번째 원문을 정리합니다. 첫 원문과 결과는 그대로 둡니다.
3. `회의01/결과`와 `회의02/결과`를 나란히 비교합니다. 네 구역과 표의 열은 같고 팀·요일·일정은 각각의 원문에 맞아야 합니다.
4. 첫 회의 값이 섞이거나 없는 날짜를 만들었다면 해당 규칙만 보완합니다. 다시 실행할 때 `회의02/재검토`처럼 새 출력 폴더를 사용합니다.
5. 스킬에는 공통 절차를, 회의별 폴더에는 원문과 결과를 보관합니다.

두 번째 확인 목록에는 다음 회의 날짜, 상대 기한의 실제 날짜, 보고서 양식과 온라인 신청의 확정 여부가 남아 있어야 합니다. [모범 결과](../../solutions/part2/chapter04/06_reuse_skill/README.md)
