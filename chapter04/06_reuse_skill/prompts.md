# 복사해서 사용할 프롬프트

앞 실습에서 연 `meeting_skill_practice` 폴더의 새 대화에서 입력합니다.

```text
$meeting-minutes
@회의02/회의록_원문.md를 정리해 주세요.
결과는 회의02/결과 폴더에 저장해 주세요.
```

목록에 나타나지 않을 때에는 파일을 직접 지정합니다.

```text
@.agents/skills/meeting-minutes/SKILL.md를 작업 지침으로 읽고 적용해 주세요.
입력은 회의02/회의록_원문.md이고 출력 위치는 회의02/결과입니다.
기존 결과가 있다면 회의02/재검토를 사용해 주세요.
```

결과에 없는 날짜가 만들어진 경우에만 다음 보완을 요청합니다.

```text
@.agents/skills/meeting-minutes/SKILL.md를 확인해 주세요.
회의02 결과에 원문에 없는 날짜가 생겼습니다.
'다음 회의 전'을 보존하고 정확한 날짜가 미정이면 [확인 필요]로 남기는 규칙만 보완해 주세요.
이미 같은 규칙이 있으면 중복해서 추가하지 마세요. 팀이나 날짜를 스킬에 고정하지 마세요.
원문과 기존 결과는 보존하고 수정한 부분을 알려 주세요.
```

규칙을 확인한 뒤 새 대화에서 같은 원문을 `회의02/재검토`에 저장하도록 요청하고 기존 결과와 비교합니다.
