# 복사해서 사용할 프롬프트

## 샘플 목록 확인

```text
@chapter04/03_mail_drafts/start/거래처_샘플.csv를 읽고 20개 거래처인지 확인해 줘.
열은 회사명, 담당자명, 직함, 메일주소인지 확인하고, 주소는 모두 example.com인지 알려 줘.
직함에는 님, 사장님, 대표님이 섞여 있어야 해. 파일은 수정하지 마.
```

## 초안 생성

```text
너는 거래처 안내 메일 초안 작성 도우미야.
@chapter04/03_mail_drafts/start/거래처_샘플.csv와 @chapter04/03_mail_drafts/start/분기_안내_메모.md를 읽고,
거래처별 메일 초안 20개를 work/ch04-03/drafts 폴더에 새 Markdown 파일로 만들어 줘.
각 파일에는 수신자, 제목, 첨부 파일을 먼저 적고,
본문은 인사말 → 분기 실적 요약 → 다음 분기 일정 안내 → 확인 요청 → 감사 인사 순서로 써 줘.
회사명, 담당자명, 직함은 CSV 그대로 사용하고, 님을 중복해서 붙이지 마.
목록이나 업무 메모에 없는 실적·금액·날짜를 만들지 마.
수신자, 첨부 파일, 회신 마감일, 최종 승인자가 미정이거나 비어 있으면 [확인 필요]로 표시해 줘.
실제 발송, 로그인, 외부 전송은 하지 말고 파일로만 저장해 줘. 원본은 수정하지 마.
초안 1·5·10·15·20번의 이름, 호칭, 누락 표시를 검토하고 생성 개수를 알려 줘.
```
