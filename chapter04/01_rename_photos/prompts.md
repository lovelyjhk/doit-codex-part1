# 복사해서 사용할 프롬프트

## 1. 시작 파일 다운로드 또는 복사

저장소의 `start/png`를 복사했다면 이 단계는 생략합니다. 직접 다운로드할 때에는 비어 있는 `work/ch04-01/png`를 먼저 준비합니다.

```text
GitHub의 Twemoji PNG 다섯 개를 work/ch04-01/png 폴더로 다운로드해 주세요.
기본 주소: https://raw.githubusercontent.com/twitter/twemoji/master/assets/72x72/
파일: 1f600.png, 1f603.png, 1f604.png, 1f60a.png, 1f680.png
저장할 폴더의 전체 경로를 먼저 확인하고 이 다섯 파일만 내려받아 주세요.
같은 이름이 있으면 덮어쓰지 말고 건너뛰세요. PNG가 정상적으로 열리는지 확인해 주세요.
이미지 내용과 형식은 원본 그대로 두세요. image_sources.txt에 각 원본 주소,
Twemoji 제작자 Twitter 및 기여자, CC BY 4.0 라이선스와 변경 없음 사실을 적어 주세요.
완료 후 성공·건너뜀·실패 건수와 파일별 전체 저장 경로를 보여 주세요.
```

## 2. 변경 계획

```text
work/ch04-01/png의 1f600.png, 1f603.png, 1f604.png, 1f60a.png, 1f680.png만 확인해 주세요.
먼저 작업 폴더의 전체 경로를 보여 주세요.
새 이름은 photo_YYYYMMDD_001.png 형식으로 만들고, 날짜는 실행하는 날의 한국 날짜를 사용해 주세요.
이 파일에는 EXIF 촬영일이 없으므로 촬영일을 찾거나 추측하지 마세요.
원래 파일명 오름차순으로 001부터 005까지 번호를 붙여 주세요.
현재 이름·새 이름·적용 날짜·충돌 여부를 표로 보여 주고 승인을 기다려 주세요.
이미지 내용과 PNG 형식, image_sources.txt와 다른 파일은 그대로 유지해 주세요.
충돌하면 덮어쓰지 말고 알려 주세요. 변경 전 SHA-256과 되돌리기 기록도 준비해 주세요.
제가 승인하기 전에는 실제 파일 이름을 바꾸지 마세요.
```

## 3. 검토 후 적용

```text
변경표를 확인했습니다. 이 표의 PNG 다섯 개 이름 변경만 적용해 주세요.
계획 이후 원본 내용이나 대상 이름이 바뀌었으면 멈춰 주세요.
변경 전후 이름과 SHA-256을 work/ch04-01/rename_receipt.json에 기록해 주세요.
성공·건너뜀·실패 건수와 최종 파일명, image_sources.txt가 그대로인지 알려 주세요.
```

## 4. 복구 계획

```text
work/ch04-01/rename_receipt.json을 기준으로 복구 계획부터 보여 주세요.
기존 이름이 이미 있거나 파일 내용이 달라졌다면 덮어쓰지 말고 멈춰 주세요.
복구도 제가 승인한 뒤에 적용해 주세요.
```
