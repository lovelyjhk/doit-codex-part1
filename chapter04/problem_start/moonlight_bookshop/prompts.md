# 달빛책방 마무리 문제 프롬프트

`moonlight_skill_practice` 연습 폴더를 연 상태에서 사용합니다. 각 생성 요청 후 파일을 검토하고, 새 대화에서 실행 요청을 입력합니다.

## 1. 달빛책방 콘텐츠 제작 계약서 초안 작성 절차를 스킬로 등록하기 ★★

```text
$skill-creator
@콘텐츠_제작_의뢰서.md와 @계약서_양식.md를 읽고 moonlight-contract 스킬을 만들어 주세요.
.agents/skills/moonlight-contract/SKILL.md 한 장에 name, description, 입력·출력·작성 순서·금지 사항·완료 기준을 적어 주세요.
의뢰서와 양식으로 검토용 초안을 만드는 절차를 스킬로 등록합니다. 입력·출력·작성 순서·금지 사항·완료 기준을 포함하고, 당사자·금액·납품일은 실행 입력에서 가져오세요. 자료에 없는 조건은 [확인 필요]로 남깁니다. 등록한 스킬을 실행해 계약서_초안.md와 계약_확인목록.md를 만들고 날짜·금액·수량·합의 상태가 원문과 일치하는지 확인하세요. 원본 양식을 보존하고 서명이나 발송은 하지 않습니다.
특정 업체·날짜·금액·문장을 지침에 고정하지 마세요. 지금은 지침만 만들고 결과 작성은 하지 마세요.
```

검토 후 새 대화에서 실행합니다.

```text
$moonlight-contract
@콘텐츠_제작_의뢰서.md와 @계약서_양식.md에 적용해 주세요.
결과는 결과/moonlight-contract 폴더에 저장해 주세요. 기존 결과가 있으면 재검토/moonlight-contract에 저장해 주세요.
```

의뢰서와 견적서를 비교하는 절차를 스킬로 등록합니다. 수량×단가와 합계를 검산하고 누락 작업·일정 차이·불분명한 비용을 찾으세요. 등록한 스킬을 실행해 견적서_검토.md를 만들고 검토 항목·문제 내용·확인 요청 표로 정리합니다. 원본 금액과 검산값을 구분하고 업체·수치를 스킬에 고정하지 마세요. 알 수 없는 비용은 [확인 필요]로 남기며 원본 견적서는 수정하지 않습니다.
특정 업체·날짜·금액·문장을 지침에 고정하지 마세요. 지금은 지침만 만들고 결과 작성은 하지 마세요.

## 3. 책방 영문 번역 절차를 스킬로 등록하기 ★★

```text
$skill-creator
@달빛책방_소개글.md와 @영문_표기_기준.md를 읽고 moonlight-translate 스킬을 만들어 주세요.
.agents/skills/moonlight-translate/SKILL.md 한 장에 name, description, 입력·출력·작성 순서·금지 사항·완료 기준을 적어 주세요.
소개글과 영문 표기 기준으로 번역하는 절차를 스킬로 등록합니다. 등록한 스킬을 실행해 책방_영문번역.md와 번역_확인목록.md를 만드세요. 한국어 원문·영어 번역 표에서 이름·날짜·수치·단위를 대조하고 [확인 필요]를 유지합니다. 특정 문장·날짜를 스킬에 고정하거나 원문에 없는 설정을 추가하지 마세요. 결과는 파일로만 저장합니다.
특정 업체·날짜·금액·문장을 지침에 고정하지 마세요. 지금은 지침만 만들고 결과 작성은 하지 마세요.
```

검토 후 새 대화에서 실행합니다.

```text
$moonlight-translate
@달빛책방_소개글.md와 @영문_표기_기준.md에 적용해 주세요.
결과는 결과/moonlight-translate 폴더에 저장해 주세요. 기존 결과가 있으면 재검토/moonlight-translate에 저장해 주세요.
```

스킬이 목록에 나타나지 않으면 `.agents/skills` 경로와 머리말을 확인하고 VS Code를 다시 엽니다. 계속 보이지 않으면 `@.agents/skills/<스킬이름>/SKILL.md를 작업 지침으로 읽고 적용해 주세요`라고 요청하며 입력·출력 경로를 함께 지정합니다. 이 경우 목록에서 스킬을 선택한 실행과 구분해 기록하세요.
