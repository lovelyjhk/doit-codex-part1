# 복사해서 사용할 프롬프트

`meeting_skill_practice`를 VS Code로 연 상태에서 사용합니다.

## 1. 지침만 만들기

```text
$skill-creator
@절차_메모.md를 기준으로 meeting-minutes 스킬을 만들어 주세요.
현재 연습 폴더의 .agents/skills/meeting-minutes/SKILL.md 한 장으로 저장하고,
머리말에 name과 description을 넣어 주세요.
실행할 때 지정한 회의록 한 개를 읽고, 지정한 새 출력 폴더에
회의록_정리본.md와 확인_목록.md를 만들도록 해 주세요.
정리본은 회의 개요, 확정된 결정, 할 일, 미정과 제안으로 구성하고,
할 일 표에는 할 일·담당·기한·근거 열을 두세요.
없는 값은 [확인 필요]로 표시하고 '다음 회의 전' 같은 상대 표현은 보존해 주세요.
제안과 보류를 확정하지 말고, 특정 회의의 팀·날짜를 스킬에 고정하지 마세요.
원본·기존 결과 덮어쓰기, 실제 연락처·계정·비밀번호 복사, 외부 전송은 금지합니다.
결정·담당·기한을 원문과 대조하는 것을 완료 기준에 넣어 주세요.
지금은 스킬 파일만 만들고 회의록 정리는 수행하지 마세요.
```

## 2. 새 대화에서 첫 원문 정리

```text
$meeting-minutes
@회의01/회의록_원문.md를 정리해 주세요.
결과는 회의01/결과 폴더에 저장해 주세요.
```

## 3. 목록에 보이지 않을 때

```text
@.agents/skills/meeting-minutes/SKILL.md를 작업 지침으로 읽고 적용해 주세요.
입력은 회의01/회의록_원문.md이고 출력 위치는 회의01/결과입니다.
기존 결과가 있다면 회의01/재검토를 사용해 주세요.
```
