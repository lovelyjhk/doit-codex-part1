# [Do it! 실습] 회의록 정리 절차를 SKILL.md 한 장으로 저장하기

같은 정리 조건을 여러 회의에 쓰도록 지침 한 장으로 저장합니다. `SKILL.md`는 코덱스가 읽는 작업 지침입니다.

1. [meeting_skill_practice](start/meeting_skill_practice/) 폴더를 저장소 밖의 새 연습 위치에 복사하고 VS Code의 [파일 → 폴더 열기]로 엽니다. `절차_메모.md`, `회의01/회의록_원문.md`, `회의02/회의록_원문.md`가 보이면 준비되었습니다.
2. 첫 원문과 절차 메모를 읽습니다. 운영팀·매주 월요일·2026-08-28과 미정인 개인 담당자·지표 제안을 구분합니다.
3. 새 대화에서 `$`를 입력해 `skill-creator`를 선택하고 [생성 프롬프트](prompts.md)를 입력합니다. 결과 위치는 `.agents/skills/meeting-minutes/SKILL.md`입니다.
4. `SKILL.md`를 열어 `name`, `description`, 입력·출력, 네 구역, 상대 기한 보존과 원본 보존 규칙이 있는지 확인합니다. 특정 회의의 팀과 날짜를 고정하면 안 됩니다.
5. 같은 폴더의 새 대화에서 `$meeting-minutes`를 선택하고 [실행 프롬프트](prompts.md)로 첫 원문을 정리합니다.
6. `회의01/결과`의 두 파일을 원문과 대조합니다. 개인 담당자를 만들지 않았고 뉴스레터 지표가 제안으로 남았는지 확인합니다.

스킬이 목록에 없으면 경로와 머리말을 확인하고 VS Code를 다시 엽니다. 계속 보이지 않으면 프롬프트의 파일 직접 지정 방법으로 결과를 확인하고, 스킬 목록에서 호출한 결과와 구분해서 기록하세요.

이 저장소의 답안은 `solutions`에 있으며 자동 설치되지 않습니다. [완료 스킬과 첫 결과](../../solutions/part2/chapter04/05_create_skill/README.md)
