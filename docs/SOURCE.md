## 실습 자료에 반영한 사항

1. 이름 입력과 인사말 출력을 분리하고, 날짜를 실행 시점에 계산했습니다.
2. 메모리 확인에 서울 인사동의 가상 책방 「달빛책방」을 사용했습니다. 새 스레드에서 짧은 문장만 입력해 가게 정보와 작업 방식이 이어지는지 확인하도록 했습니다.
3. 메모리의 즉시 반영이나 전체 대화 재현을 보장하지 않습니다. 새 스레드에서 파일을 지목할 때는 파일명 또는 파일 태그를 사용하도록 안내했습니다.
4. diff의 `Review`는 변경 내용 확인 기능으로 설명했습니다. 이미 저장된 수정에 일반적인 `Approve / Accept / Apply` 버튼이 반드시 있다는 설명은 사용하지 않았습니다.
5. 누락된 입력 자료 `ch03/ex03_2.md`를 새로 만들고 원고의 `solutions/ch03/ex03_2.md`, `solutions/ch03/ex03_3.md` 답안 경로를 유지했습니다.
6. 승인 방식 비교에는 격리된 폴더에서 같은 파일 생성 요청을 비교하는 방법과 관찰표를 제공했습니다. 선택할 수 없는 모드는 미지원으로 기록하며, 전체 권한은 설명 비교로 대체할 수 있습니다.
7. 1장 본문에서 형식을 설명하기 위해 언급한 Word·Excel 자료는 별도 프로그램 없이 확인할 수 있는 Markdown·CSV 예시로 제공하고, 실행용 프롬프트도 실제 파일명과 맞췄습니다. 형식 대응은 [예시 파일 목록](SAMPLE_FILES.md)에 정리했습니다.
8. 최신 원고의 노래 3곡·책 분야·음료를 묶는 「오늘의 추천」 확장 예시와 실행 전 다섯 가지 확인 질문을 추가했습니다. 날씨 수치는 실습일에 다시 확인하고, 추천 조합의 예시와 실제 실행 기록을 구분했습니다.
