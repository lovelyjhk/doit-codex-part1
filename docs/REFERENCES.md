# 공식 참고 문서

확인일: 2026-09-05. 화면은 버전·계정·연결된 실행 환경에 따라 달라질 수 있습니다.

- [Codex IDE extension](https://learn.chatgpt.com/docs/codex/ide): 확장 설치, 패널 열기, 편집기 문맥과 변경 검토.
- [Memories](https://learn.chatgpt.com/docs/customization/memories): 로컬 메모리, 백그라운드 생성과 지연, 대화별 사용·생성 설정.
- [Agent approvals & security](https://learn.chatgpt.com/docs/agent-approvals-security): 작업 가능 범위와 승인 요청 정책, 작업 폴더 안의 자동 편집·실행.
- [Automatic approval reviews](https://learn.chatgpt.com/docs/agent-approvals-security#automatic-approval-reviews): 승인이 필요한 작업을 자동 검토하는 방식과 한계.
- [VS Code 다운로드](https://code.visualstudio.com/Download): Windows 설치 파일.
- [Python Windows 다운로드](https://www.python.org/downloads/windows/): 파이썬 설치 파일.

메모리는 모든 대화를 그대로 보관하거나 새 대화에 즉시 반영하는 기능으로 설명하지 않습니다. 브라우저 음악 재생 가능 여부도 메모리와 별개로 확인합니다. `Review`로 diff를 보는 것과 파일·명령 실행 권한을 승인하는 것은 구분합니다.
