## 첫째마당 파일

입문자가 Office 설치 없이 내용을 열어 볼 수 있도록 1장 예시는 Markdown과 CSV로 제공합니다. 실행용 프롬프트는 제공 파일명과 일치합니다. `.md`는 텍스트 문서이며, `.csv`는 쉼표로 열을 나눈 표 데이터입니다.

| 원고의 예시 또는 설명 | 제공 파일 | 용도 |
|---|---|---|
| data.xlsx를 읽어 합계 구하기 | [sales_2026.csv](../chapter01/examples/sales_2026.csv) | 같은 파일 작업 흐름을 CSV 읽기와 합계로 연습 |
| sales_2026.csv 월별 매출 | [sales_2026.csv](../chapter01/examples/sales_2026.csv) | 월별 집계와 누락값 확인 |
| doc/작업용_보고서.docx 교정 | [report.md](../chapter01/examples/report.md) | 뜻·이름·숫자를 보존하는 교정 |
| 문서 요약·발표 구성 | [document.md](../chapter01/examples/document.md) | 요약과 단계별 지시 |
| PMO 결정 사항·액션 아이템 | [meeting.md](../chapter01/examples/meeting.md) | 담당자·마감일의 불확실성 처리 |
| AGENTS.md 반복 규칙 | [AGENTS.template.md](../chapter01/templates/AGENTS.template.md) | 별도 연습 폴더에서 AGENTS.md로 복사 |
| hello.py | [단계별 대응표](CONTENTS.md) | 생성, 입력, 날짜, 한 줄 수정 |
| hello 프로젝트 README.md | [README.md](../chapter02/04_file_tag/start/README.md) | @ 파일 태그 참고 자료 |
| ex03_2.md | [ch03/ex03_2.md](../ch03/ex03_2.md) | 2장 마무리 5줄 요약 입력 자료 |

위 1장 예시는 Word 문서의 실제 그림·서식 보존이나 Excel 통합 문서의 수식·시트 보존을 검증하는 예제는 아닙니다. 그 기능이 필요한 작업에서는 원래 형식의 파일을 따로 준비해야 합니다.

매출 자료는 가상 거래 6건입니다. 2026-03-20의 금액 하나를 일부러 비워 두었으며, 이는 오류로 채울 칸이 아니라 확인 필요로 남겨야 하는 값입니다.

## 둘째마당 파일

둘째마당에는 문서·이미지·CSV·XLSX·PPTX·PDF와 규칙 파일을 제공합니다. [파일명과 실제 경로 목록](PART2_FILES.md)에서 찾은 뒤 각 실습 안내의 시작 자료만 복사하세요. 같은 파일명이 있어도 실습에 따라 내용이 다르므로 여러 폴더의 자료를 합치지 않습니다.
