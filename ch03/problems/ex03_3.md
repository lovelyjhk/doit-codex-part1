# 2장 마무리 문제 2 코덱스 승인 방식 이해하기 ★★

같은 작업을 요청했을 때 Codex가 자동으로 처리하는 부분과 사용자가 확인하는 부분의 차이를 정리하세요. 원고의 비교 대상은 ‘승인 요청’, ‘나 대신 승인’, ‘전체 권한’입니다.

1. 다른 자료가 없는 새 연습 폴더를 준비합니다. 설정을 바꾸기 전에 원래 선택된 값을 메모합니다.
2. Codex의 권한·승인 설정을 열어 표시된 이름과 설명을 읽습니다. 선택 항목이 없으면 미지원으로 기록합니다.
3. 사용할 수 있는 각 방식에서 서로 다른 빈 폴더와 새 스레드를 열고 아래 **동일한 요청**을 입력합니다. 새 파일을 만드는 작은 작업만 비교합니다.

```text
현재 연습 폴더에 approval_check.txt를 새로 만들고,
내용은 "승인 방식 비교 실습" 한 줄로 작성해 줘.
같은 이름의 파일이 이미 있으면 덮어쓰지 말고 멈춰 줘.
다른 파일을 수정하거나 프로그램 실행, 삭제, 외부 접근은 하지 마.
```

4. 사용자에게 질문했는지, 자동 검토가 표시됐는지, 파일이 생겼는지 [관찰표](../approval-observation.md)에 기록합니다. 파일 편집이 이미 허용된 경우 이 작은 요청은 여러 방식에서 모두 자동 처리될 수 있습니다.
5. 전체 권한 사용이 허용되지 않거나 원치 않는 경우에는 **설정 설명만 비교**합니다. 실행했다고 기록하지 않습니다. 차이를 만들기 위해 삭제·외부 전송 등을 추가하지 않습니다.
6. 비교가 끝나면 원래 설정으로 되돌립니다. 승인 요청 정책과 작업 가능한 범위가 어떻게 다른지 두 문장으로 설명합니다.

확인: 실제 관찰과 설정 설명을 구분했는지, ‘모든 수정마다 승인 창이 뜬다’고 단정하지 않았는지 확인하세요.
