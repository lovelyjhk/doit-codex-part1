# 2장 마무리 문제 1 @ 파일 태그로 참고 파일 지정하기 ★

특정 파일을 참고 자료로 지정하고, 태그를 사용하지 않았을 때와 결과를 비교하세요.

입력 파일: [ch03/ex03_2.md](../ex03_2.md)

모범 답안: [solutions/ch03/ex03_2.md](../../solutions/ch03/ex03_2.md)

## 풀이 순서

1. 새 연습 폴더 안에 `ch03` 폴더를 만들고 입력 자료 `ex03_2.md`만 복사합니다. VS Code에서는 상위 연습 폴더를 엽니다.
2. 새 스레드에서 `@ex03_2`를 입력하고 **ch03/ex03_2.md**를 선택합니다. 같은 이름의 답안 파일이 보이면 선택하지 않습니다.
3. 파일 태그와 함께 다음 문장을 입력합니다.

```text
@ch03/ex03_2.md를 기준으로 프로젝트의 목적과 ch03 폴더 내의 실습 순서를 5줄로 요약해 줘.
파일에 없는 내용은 만들지 말고 파일 수정이나 명령 실행은 하지 마.
```

4. 다른 새 스레드에서 태그 없이 비교합니다. 이전 응답을 복사하거나 대화 분기를 사용하지 않습니다.

```text
프로젝트의 목적과 ch03 폴더 내의 실습 순서를 5줄로 요약해 줘.
파일에 없는 내용은 만들지 말고 파일 수정이나 명령 실행은 하지 마.
```

5. [비교 기록](../tag-observation.md)에 참고한 파일, 정확성, 줄 수, 추가 탐색 여부를 적습니다. 태그가 없어도 파일을 찾아 같은 결과를 낼 수 있습니다. 반드시 오답이 나오거나 처리 시간·토큰이 줄어든다고 가정하지 않습니다.

확인: 첫 줄에 목적이 있고, 나머지 네 줄에 자료에 적힌 순서가 들어 있는지 대조하세요.
