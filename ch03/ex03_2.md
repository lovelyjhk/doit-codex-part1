# hello 프로젝트와 실습 순서

## 프로젝트의 목적

파이썬 인사말 프로그램을 만들고 수정하면서 Codex의 파일 생성, 같은 스레드의 후속 요청, 참고 파일 지정, 변경 검토와 승인 방식을 익힙니다.

## 본문에서 준비한 내용

hello.py에 “안녕하세요, Codex!”를 출력하는 코드를 만든 뒤 이름 입력과 오늘 날짜 출력을 추가했습니다. README.md에는 프로젝트 목적과 실행 방법을 적었습니다. 인사말을 “Hello, Do it! Codex!”로 바꾸는 한 줄 변경도 diff에서 확인했습니다.

## ch03 폴더의 실습 순서

1. ex03_2.md를 읽고 이 프로젝트의 목적과 아래 실습 순서를 확인합니다.
2. 새 스레드에서 이 파일을 @ 파일 태그로 지정해 프로젝트 목적과 실습 순서를 5줄로 요약합니다.
3. 별도의 새 스레드에서 태그 없이 같은 요청을 하고, 두 결과의 근거와 누락된 내용을 비교해 기록합니다.
4. ex03_3 문제에서 승인 방식을 살펴보고 같은 작업에 대한 자동 처리와 사용자 확인의 차이를 정리합니다.

## 실습 규칙

- 이 입력 자료는 수정하지 않습니다.
- 파일에 없는 프로젝트 목적이나 실습 순서를 만들지 않습니다.
- 승인 방식은 화면에서 확인한 이름과 실제 동작을 기록합니다.
- 전체 권한을 켜기 어렵다면 설정 설명을 읽고 비교한 것으로 표시합니다.
