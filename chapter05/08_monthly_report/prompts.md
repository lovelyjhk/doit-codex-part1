```text
sales_sample.csv를 읽고 7월 월말 보고용 july-sales-report.xlsx를 만들어 줘.
[요구 사항]
- 데이터 시트에는 원본의 열 이름과 데이터 6행을 유지해 줘.
- 요약 시트에는 5·6·7월의 revenue_krw 합계와 7월의 전월 대비 증감액·증감률을 넣어 줘.
- 증감액은 ‘7월 매출−6월 매출’, 증감률은 ‘증감액÷6월 매출’로 계산해 줘. 증감률은 백분율로 소수점 첫째 자리까지 표시해 줘.
- 차트 시트에는 월별 전체 매출을 보여 주는 엑셀 꺾은선형 차트를 넣어 줘. 제목은 ‘2026년 5~7월 월별 매출’, 가로축은 ‘월’, 세로축은 ‘매출액(원)’으로 표시해 줘.
- 꺾은선의 각 점 위에 월별 매출액을 숫자로 표시하고, 금액에는 천 단위 쉼표를 넣어 줘.
- 월은 시간순으로 정렬하고, 흰 배경과 읽기 쉬운 한글 글꼴을 사용해 줘. 차트는 요약표를 참조하며 Excel에서 편집할 수 있어야 해.
- 원본 CSV와 기존 파일은 변경하지 마. 같은 이름의 파일이 있으면 덮어쓰기 전에 알려 줘.
- 먼저 집계 기준과 만들 파일, 현재 PC에서 사용할 실행 방법을 설명해 줘. 준비가 필요한 항목이 있으면 알려 주고, 내 승인 뒤에 실행해 줘.
```
