1. 새 연습 폴더에 [앞 실습의 결과](../../solutions/part2/chapter05/08_monthly_report/july-sales-report.xlsx)을 복사합니다.

3. 결과 `july-sales-report-final.xlsx`을 열어 아래 값을 비교합니다. 원본과 이전 결과는 보존합니다.

A는 -210,000원(-5.2%), B는 +520,000원(+14.1%), 전체는 +310,000원(+4.0%)입니다. 전체 증감률은 전체 금액으로 계산합니다. 기존 월별 차트와 상품별 차트가 겹치지 않고, 막대 축이 0부터 시작하는지 확인하세요.
