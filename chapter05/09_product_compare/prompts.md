먼저 입력 파일과 실행 계획을 확인합니다. 준비가 끝나면 실행을 승인하세요.

```text
july-sales-report.xlsx를 바탕으로 상품별 전월 비교를 추가하고 july-sales-report-final.xlsx로 저장해 줘.
[요구 사항]
- 요약 시트에 ‘상품 / 6월 매출 / 7월 매출 / 증감액 / 증감률’ 표를 추가해 줘. 각 증감률은 해당 상품의 6월 매출을 기준으로 계산해 줘.
- 전체 행의 증감률은 상품별 증감률의 평균이 아니라, 전체 증감액을 전체 6월 매출로 나누어 계산해 줘.
- 차트 시트에 상품 A·B의 6월과 7월 매출을 나란히 비교하는 묶은 세로 막대형 차트를 추가해 줘. 제목은 ‘2026년 6·7월 상품별 매출 비교’, 가로축은 ‘상품’, 세로축은 ‘매출액(원)’으로 표시하고 금액 축은 0부터 시작해 줘.
- 6월과 7월을 다른 색으로 구분하고 범례에 월을 표시해 줘. 전체 합계 행은 차트의 상품 항목에 포함하지 마.
- 기존 월별 차트는 유지하고 두 차트가 겹치지 않게 배치해 줘.
- 요약표에서 감소한 값에는 음수 기호를 표시하고 필요한 부분만 색으로 강조해 줘.
- 상품별 증감액의 합계가 전체 증감액과 일치하는지 확인해 줘. 원본에 없는 원인은 추측하지 마.
- 원본과 기존 결과 파일은 보존해 줘. 먼저 추가할 내용을 보여 주고 승인 뒤에 실행해 줘.
```
