# [Do it! 실습] 요약·데이터·차트 3개 시트 만들기

출판 준비용 초안입니다. 데이터는 학습용으로 만든 가상 자료입니다.

1. 이 폴더의 `start` 폴더를 별도 연습 위치에 복사하세요. VS Code의 [파일 → 폴더 열기]에서 복사한 폴더를 엽니다.
2. 파일 목록을 확인합니다. 원본 파일 이름은 바꾸지 않습니다. 다른 실습의 결과를 이미 가지고 있다면 이 실습에 필요한 파일만 같은 폴더에 복사해도 됩니다.
3. [프롬프트](prompts.md)를 Codex 입력창에 복사합니다. `@` 파일은 추천 목록에서 실제 파일을 선택하세요. 요청한 파일 외에 변경할 내용이 없는지 확인합니다.
4. 결과를 엽니다. Excel에서 3개 시트 이름, 데이터 48행, 필터·머리글 고정, 수식과 차트를 확인하세요. 1월 59,000원, 12월 103,000원, 연 합계 972,000원을 대조하세요.
5. [모범 답안](../../solutions/part2/chapter05/02_excel_report/README.md)과 비교하세요. 표현은 달라도 원본과 계산 기준이 같아야 합니다. 잘못된 숫자가 있다면 원본 행을 지정해 다시 요청하세요.

시작 파일: [start](start/) · [5장 목록](../README.md)

엑셀을 만들 도구가 없는 환경이면 필요한 도구와 설치 명령부터 확인하세요. CSV 파일 이름만 `.xlsx`로 바꾼 파일은 엑셀 보고서가 아닙니다. 제공된 모범 답안 XLSX를 먼저 열어 결과 모양을 확인할 수 있습니다.
