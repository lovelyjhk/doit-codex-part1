# 5장 최신 실습 입력 자료

모든 값은 학습용 가상 자료입니다. 원본 파일은 수정하지 않습니다.

- `sales_sample.csv`: 2026년 5~7월 상품 A·B, 6행. `month`는 월, `product`는 상품, `units`는 수량(개), `revenue_krw`는 매출(원)입니다.
- `large_sales_sample.csv`: 1,000행, 29,289바이트. `date`는 날짜, `region`은 지역, `category`는 분류, `sales`는 매출(원), `quantity`는 수량(개)입니다. 거래 ID는 없습니다.
- `july_sales_chart_review.xlsx`: 마무리 문제5에서 `sales_sample.csv`와 함께 대조할 엑셀 보고서입니다. [상품별 비교 실습의 완성 예제](../../solutions/part2/chapter05/09_product_compare/july-sales-report-final.xlsx)를 그대로 복사했으며 요약·데이터·차트 시트와 월별·상품별 차트가 들어 있습니다. 이 파일은 검수용이므로 수정하지 않습니다.

두 번째 파일은 처리 방법을 익힐 작은 표본입니다. 파일 크기만으로 실제 대용량 처리 성능을 판단하지 않습니다. 7월 기록은 광주 125행만 있으므로 다른 지역을 실적 0으로 확정하지 않습니다.
