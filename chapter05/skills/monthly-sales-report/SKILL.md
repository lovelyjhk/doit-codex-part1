# 월말 판매 보고서 만들기

전체 실적의 증감과 상품별 차이를 함께 설명하는 새 `.xlsx` 보고서를 만든다. 보고월 선택만으로 전월·당월 비교표와 편집 가능한 Excel 차트가 함께 바뀌어야 한다.

## 입력과 원본 확인

- 사용자 요청에서 입력 CSV, 보고월(`YYYY-MM`), 출력 `.xlsx` 경로를 확인한다. 실습 기본값은 `inputs/sales_sample.csv`, `2026-07`, `results/skill-july-report.xlsx`이다. 파일 경로는 현재 작업 폴더 기준으로 해석한다.
- 기본 열은 `month`, `product`, `units`, `revenue_krw`이다. 각각 월, 상품, 판매 수량, 매출액(원)을 뜻한다. 실습자료는 한 행이 한 달·한 상품의 집계값이다.
- 원본의 열, 행 수, 기간, 상품, 빈값, 숫자로 읽히지 않는 값, 월·상품 중복을 확인한다. 빈 매출을 0으로 바꾸거나 중복 행을 임의로 삭제하지 않는다. 음수나 중복의 의미가 불명확하면 처리에 필요한 질문만 묻는다.
- 다른 자료의 열 이름이 달라도 의미가 명확하면 대응시킨다. 통화·금액 단위, 월의 의미, 한 행의 기준이 불분명하면 해당 항목만 확인한다. 다른 통화를 원화로 간주하거나 환산하지 않는다.
- 자료에 있는 달 중 달력상 바로 전월의 자료도 있는 달만 비교 대상으로 삼는다. 기본 실습자료의 선택지는 `2026-06`, `2026-07`이다. 요청한 달을 비교할 수 없으면 가능한 달과 빠진 기간을 알려 주고 보고월을 확인한다.

## 통합 문서 구성

| 시트 | 포함할 내용 |
| --- | --- |
| 요약 | `B3`의 보고월 드롭다운, 상품별·전체 매출 비교표, 그 아래의 묶은 세로 막대형 Excel 차트, 보고에 쓸 짧은 관찰 문장 |
| 데이터 | 원본의 모든 행과 열, 필요한 계산용 보조 열, 첫 행 고정과 필터 |

- 원본 CSV는 수정하지 않는다. 원본 값과 추가한 보조 열을 구분하고, 파일명·자료의 기간·집계 기준·금액 단위(원)를 보고서에 적는다.
- 보고월 셀만 쉽게 찾도록 강조하고, 금액은 천 단위 쉼표, 증감률은 소수 첫째 자리까지 표시한다. 장식보다 상품명과 숫자가 읽히는 배치를 우선한다.
- 상품별 비교표에는 `상품`, `전월 매출`, `선택월 매출`, `증감액`, `증감률`, `확인 상태`를 넣고 마지막 행에 전체를 표시한다. 해당 비교 기간의 한쪽에만 있는 상품도 누락하지 않는다. 실습자료는 `A8:F11`에 표, `A15:F31` 영역에 차트를 배치하여 월 선택·표·차트를 한 화면에서 확인하게 한다. 상품 수가 달라지면 표와 차트가 겹치지 않도록 늘린다.

## 월 선택과 계산

- 보고월 드롭다운에는 지원하는 달만 넣는다. `SUMIFS`, `COUNTIFS` 등 Excel에서 지원하는 수식으로 보고월을 참조하고, 통합 문서가 자동 계산되도록 저장한다. VBA 매크로와 외부 데이터 연결은 사용하지 않는다.
- 보고월과 선택 목록의 월은 `YYYY-MM` 텍스트로 저장한다. 목록 원본은 데이터 시트의 텍스트 셀에 이름을 붙여 참조하고, 저장 후에도 `2026-06`이 `Jun-2026` 같은 다른 문자열로 바뀌지 않았는지 확인한다. 검증할 때는 실제 목록에 들어 있는 값을 선택 셀에 넣는다.
- 합계가 0이라는 이유만으로 기록이 없다고 판단하지 않는다. 월·상품별 기록 수를 먼저 확인하여 기록이 있으면 실제 합계(0 포함)를 표시하고, 기록이 없으면 `자료 없음·확인 필요`로 표시한다.
- 비교할 양쪽 기록이 있을 때 증감액을 계산한다. 증감률은 `(당월-전월)/전월`이며, 전월이 0이거나 비교 기록이 없으면 `계산 불가`와 이유를 표시한다. 빈값을 계산 과정에서 0으로 취급하지 않는다.
- 전체 합계는 해당 월에 확인된 기록의 합계이다. 상품별 누락이 있으면 전체 실적이 완전하게 취합되었다고 단정하지 말고 확인 상태를 함께 보여 준다.
- 차트 계열을 비교표의 계산 셀에 연결한다. 제목에 비교하는 두 달, 가로축에 상품, 세로축에 `매출액(원)`, 범례에 전월·당월을 표시하고 세로축은 0에서 시작한다. 자료가 없는 값은 차트에서도 0원 막대로 표현하지 않는다.
- 차트 제목과 범례의 월도 계산 셀에 연결한다. 막대 값만 바뀌고 범례는 최초 작성한 월로 남는지 확인하며, 월을 바꾼 뒤에도 세로축 최솟값 0이 유지되어야 한다.
- 보고월이 바뀌면 제목, 비교표, 차트, 화면의 보고 문장도 같은 기간을 가리키도록 한다. 설명 문장을 수식으로 연동하기 어렵다면 문장마다 작성 기준 월을 명시하여 다른 달의 설명으로 오해하지 않게 한다.
- 관찰한 증감과 상품별 기여를 설명한다. 판매량 변화의 배경을 광고·재고·고객 행동 등으로 추측하지 말고, 원인을 확인하려면 필요한 추가 자료를 적는다.

## 생성과 검증

- 현재 Windows 환경의 Excel 및 사용할 수 있는 실행 도구를 먼저 확인하고, 수식과 편집 가능한 차트를 만들 수 있는 방법을 선택한다. 특정 언어나 라이브러리의 설치를 전제로 하지 않는다. 사용자의 열려 있는 통합 문서를 수정하거나 닫지 않는다.
- 출력 파일이 이미 있으면 덮어쓰지 않고 날짜 또는 순번을 붙인 새 이름으로 저장한 뒤 실제 경로를 알려 준다.
- 원본을 별도로 집계한 결과와 전월·당월 전체 합계 및 상품별 증감을 대조한다. 지원하는 각 보고월로 셀 값을 바꾸고 재계산하여 비교표와 차트의 참조 값이 바뀌는지 확인한 뒤 요청한 보고월로 되돌려 저장한다.
- 파일을 다시 열 수 있는지, 기록 없음과 실제 0이 구별되는지, 수식 오류가 없는지 확인한다. 가능한 경우 Excel 화면에서 제목·축·범례·겹침도 확인한다. 실제로 하지 못한 화면 검증은 완료했다고 보고하지 않는다.
- 완료 응답은 파일 경로, 핵심 관찰 2~3개, 검증 결과, 사람이 확인할 사항으로 짧게 정리한다.
- 파일 안의 월 선택은 이미 담긴 데이터로 즉시 재계산하는 기능이다. CSV에 새 달이나 수정 내역이 생기면 이 스킬을 다시 실행해 새 보고서를 만들어야 한다. 스킬 자체가 매달 자동 실행되거나 CSV와 자동 동기화되는 것은 아니다.
