# 월말 판매 보고 스킬 사용하기

4장에서 배운 스킬은 반복하는 작업의 지침을 저장해 두고 다시 사용하는 방법입니다. 이번 `monthly-sales-report` 스킬에는 원본 자료 확인, 상품별 전월 비교, 엑셀 보고서 생성, 결과 검증 순서를 담았습니다. 매번 긴 요구 사항을 다시 쓰는 대신 입력 파일과 보고월, 결과 파일명만 바꾸어 요청합니다.

이 폴더는 실습용 스킬 배포본입니다. 아래 경로로 복사하기 전에는 현재 프로젝트에 설치된 것으로 간주하지 않습니다.

## 1. 실습 폴더에 스킬 복사하기

Windows의 VS Code에서 실습자료의 `inputs` 폴더가 들어 있는 상위 폴더를 엽니다. 예를 들어 `ch05_practice_20260906`을 열었다면, 탐색기에서 `.agents` 폴더와 그 안의 `skills` 폴더를 만듭니다. 제공된 `skills/monthly-sales-report` 폴더를 `.agents/skills` 안에 복사합니다. 같은 이름의 스킬이 이미 있으면 덮어쓰지 말고 기존 내용을 먼저 확인합니다.

```text
ch05_practice_20260906/
  inputs/
    sales_sample.csv
  .agents/
    skills/
      monthly-sales-report/
        SKILL.md
```

현재 공식 문서의 프로젝트 스킬 경로는 `.agents/skills`입니다. 개인의 여러 프로젝트에서 쓸 스킬은 사용자 폴더의 `.agents/skills`에 둘 수 있지만, 이 실습은 위의 프로젝트 폴더만 사용합니다. [OpenAI 공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills#where-to-save-skills)

## 2. Codex에서 스킬 호출하기

VS Code의 Codex 입력창에서 `$`를 입력해 `monthly-sales-report`를 선택합니다. 목록에 나타나지 않으면 `SKILL.md`의 위치를 확인하고 Codex를 다시 시작합니다. 스킬은 이름을 지정해 부를 수도 있고, 요청이 설명과 일치하면 Codex가 선택할 수도 있습니다. [OpenAI 공식 스킬 호출 안내](https://learn.chatgpt.com/docs/build-skills#how-codex-uses-skills)

선택한 뒤 다음처럼 요청합니다.

```text
$monthly-sales-report
입력 파일: inputs/sales_sample.csv
보고월: 2026-07
출력 파일: results/skill-july-report.xlsx

팀장에게 보고할 월말 판매 보고서를 만들어 줘.
전체 매출의 변화와 상품별 차이를 함께 설명해 줘.
```

스킬은 Codex가 따를 지침입니다. 별도의 프로그램 설치 파일이 아니므로, 보고서를 생성할 때는 현재 컴퓨터에서 사용할 수 있는 Excel과 실행 도구를 확인합니다. 기존 원본과 보고서는 덮어쓰지 않습니다.

## 3. 월을 바꾸고 결과 확인하기

완성된 `.xlsx` 파일을 Excel에서 엽니다. `요약` 시트의 `B3` 셀을 선택하고 드롭다운에서 보고월을 바꿉니다. 이 실습자료에서는 전월과 비교할 수 있는 `2026-06`, `2026-07`을 선택할 수 있습니다. `2026-05`는 4월 자료가 없어 선택지에 넣지 않습니다.

- `2026-07`을 선택하면 6월 7,730,000원과 7월 8,040,000원을 비교합니다. 전체 증감액은 310,000원입니다.
- `2026-06`을 선택하면 5월 6,800,000원과 6월 7,730,000원을 비교합니다. 전체 증감액은 930,000원입니다.
- 보고월을 바꿀 때 상품별 비교표, 차트 제목과 막대 값, 보고 문장의 기준 기간이 함께 맞는지 확인합니다.

위 숫자는 제공된 가상 실습자료의 대조 기준입니다. 다른 파일로 실행할 때는 그 파일에서 다시 집계해야 합니다. 화면이 바뀌지 않거나 계산 오류가 있으면 파일명, 선택한 월, 실제 오류 내용을 Codex에 알려 수정하도록 요청합니다.

## 4. 다음 달 자료로 다시 요청하기

엑셀에서 월을 선택하는 것은 파일 안에 이미 들어 있는 자료를 다시 계산하는 일입니다. 원본 CSV에 새로운 달이 추가되거나 기존 수치가 수정되어도 만들어 둔 보고서가 자동으로 갱신되지는 않습니다. 새 자료를 준비한 뒤 같은 스킬에 새 입력 파일과 보고월, 새 출력 파일명을 지정하여 보고서를 다시 만듭니다.

예를 들어 실제로 7월과 8월 자료가 들어 있는 CSV를 준비했다면 다음과 같이 요청합니다. 현재 제공된 실습 CSV에는 8월 자료가 없습니다.

```text
$monthly-sales-report
입력 파일: inputs/sales_through_2026-08.csv
보고월: 2026-08
출력 파일: results/skill-august-report.xlsx
```

스킬은 반복 요청을 간단하게 만듭니다. 정해진 날짜에 스스로 실행하는 예약 기능은 이 실습에 포함하지 않습니다.

공식 문서 확인일: 2026-09-06. 스킬은 필수 `name`, `description`을 포함한 `SKILL.md`로 만들 수 있으며, 현재 문서는 프로젝트 `.agents/skills`와 Codex IDE의 `$` 호출을 안내합니다. [OpenAI Build skills](https://learn.chatgpt.com/docs/build-skills)
