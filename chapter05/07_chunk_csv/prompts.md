# 복사할 프롬프트

```text
@large_sales_sample.csv의 파일 크기와 머리글을 먼저 확인해 줘.
파이썬 표준 라이브러리 csv와 itertools.islice로 200행씩 읽는 chunk_sales.py를 만들어 줘.
read(), readlines(), list(reader)로 전체 파일을 한꺼번에 읽지 마.
매출은 정수 원 단위로 누적하고 행 수, 청크 수, 매출·수량 합계, 지역별 매출을
chunk_summary.json에 저장해 줘. 빈 값이나 숫자 변환 오류가 있으면 행 번호와 함께 중단해 줘.
원본을 수정하지 말고 실행 명령과 합계 대조 방법을 알려 줘.
```
