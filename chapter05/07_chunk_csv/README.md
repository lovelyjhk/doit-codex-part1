# [Do it! 실습] 큰 CSV를 나눠서 처리하기

출판 준비용 초안입니다. 데이터는 학습용으로 만든 가상 자료입니다.

1. 이 폴더의 `start` 폴더를 별도 연습 위치에 복사하세요. VS Code의 [파일 → 폴더 열기]에서 복사한 폴더를 엽니다.
2. 파일 목록을 확인합니다. 원본 파일 이름은 바꾸지 않습니다. 다른 실습의 결과를 이미 가지고 있다면 이 실습에 필요한 파일만 같은 폴더에 복사해도 됩니다.
3. [프롬프트](prompts.md)를 Codex 입력창에 복사합니다. `@` 파일은 추천 목록에서 실제 파일을 선택하세요. 요청한 파일 외에 변경할 내용이 없는지 확인합니다.
4. 결과를 엽니다. 기본 200행 청크로 실행하면 데이터 2,400행, 청크 12개, 매출 12,120,000원, 수량 7,200개가 나옵니다. 다른 청크 크기로 실행해 합계가 같은지 확인하세요.
5. [모범 답안](../../solutions/part2/chapter05/07_chunk_csv/README.md)과 비교하세요. 표현은 달라도 원본과 계산 기준이 같아야 합니다. 잘못된 숫자가 있다면 원본 행을 지정해 다시 요청하세요.

시작 파일: [start](start/) · [5장 목록](../README.md)

파일 탐색기에서 CSV를 우클릭하고 [속성]으로 크기를 확인하세요. PowerShell에서는 `Get-Item .\large_sales_sample.csv | Select-Object Name,Length`로 확인합니다. 이 샘플은 크기가 작은 2,400행으로 처리 방법을 익히는 용도이며, 큰 파일은 모범 답안의 확장 생성기를 사용합니다. 기본 실습에서 큰 파일을 생성할 필요는 없습니다.
