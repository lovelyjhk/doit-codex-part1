# 처리 기준

학습용 가상 데이터입니다. 원본 `quality_sales.csv`는 변경하지 않습니다.
빈 값, 음수 매출, 100,000원 초과 매출, 중복 ID를 각각 확인 후보로 표시합니다.
빈 값은 채우지 않고, 음수는 반품 여부를 확인하며, 큰 매출도 오류로 단정하지 않습니다.
중복 ID는 첫 행을 포함해 해당 ID의 모든 행에 표시합니다.
`quality_flagged.csv`에는 원본 4열과 값·행 순서를 유지하고 `flags` 열만 덧붙입니다.
처리 규칙과 각 후보 수, 원본 기준 합계를 `quality-policy.md`에 적습니다.
