# 지점 자료에서 7월 실적을 뽑고 빠진 지역 확인하기

1. 새 연습 폴더에 `start/large_sales_sample.csv`을 복사합니다.
2. VS Code에서 폴더를 열고 [프롬프트](prompts.md)를 입력합니다. 코덱스가 설명한 실행 방법을 확인한 뒤 승인합니다.
3. 결과 `july-branch-check.xlsx, chunk-log.txt`을 열어 아래 값을 비교합니다. 원본과 이전 결과는 보존합니다.

200행씩 5개 묶음, 전체 1,000행, 선택 125행, 다른 기간 875행입니다. 광주 4,040,000원·996개이며 다른 세 지역의 금액과 수량은 빈칸이어야 합니다. 첫 묶음 선택 매출은 786,250원, 선택 날짜는 7월 3~27일입니다.
