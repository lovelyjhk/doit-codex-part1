# 지점 자료에서 7월 실적을 뽑고 빠진 지역 확인하기

먼저 입력 파일과 실행 계획을 확인합니다. 준비가 끝나면 실행을 승인하세요.

```text
계획대로 large_sales_sample.csv를 200행씩 읽어 july-branch-check.xlsx와 chunk-log.txt를 만들어 줘. 필요한 스크립트도 현재 폴더에 만들고 실행해 줘.
[요구 사항]
- 머리글을 제외한 데이터 최대 200행씩 CSV 형식에 맞게 읽어 줘. 원본 전체나 처리한 묶음 전체를 계속 메모리에 보관하지 마.
- 2026-07-01 이상, 2026-08-01 미만인 기록만 선택해 줘. 다른 기간의 기록은 원본에서 삭제하지 말고 이번 집계에서만 제외해 줘.
- 오류가 있는 날짜나 숫자를 발견하면 임의로 바꾸거나 제외하지 말고, 위치와 처리 기준을 먼저 알려 줘.
- XLSX의 ‘추출자료’ 시트에는 선택한 원본 기록을 그대로 넣어 줘.
- ‘지역별 확인’ 시트에는 광주·대전·부산·서울 순서로 7월 조건에 맞는 기록 수, 매출 합계, 수량 합계, 확인 상태를 표시해 줘.
- 해당 지역의 7월 기록이 없으면 매출과 수량은 빈칸으로 두고 ‘자료 없음·확인 필요’로 표시해 줘. 매출 0원으로 추정하지 마.
- 기록이 있는 지역도 ‘기록 있음·월 전체 자료 여부 확인 필요’로 표시해 줘. 일부 기록이 있다는 이유만으로 해당 월의 자료가 모두 있다고 판단하지 마.
- ‘검수’ 시트에는 원본 파일명, 기간 조건, 처리 행 수, 선택 행 수, 다른 기간으로 제외한 행 수, 선택한 매출·수량 합계, 선택된 기록의 첫 날짜와 마지막 날짜를 적어 줘.
- chunk-log.txt에는 묶음별 처리·선택·제외 행 수와 누적 합계를 남기고, 마지막 전체 결과도 기록해 줘.
- 원본과 기존 파일은 보존하고, 실제 실행한 명령과 결과 파일 위치를 알려 줘.
```
