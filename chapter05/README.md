5~7월 상품별 실습에는 `inputs/sales_sample.csv` 6행을 씁니다. 지점 실습에는 `inputs/large_sales_sample.csv` 1,000행을 씁니다. 마무리 문제5는 같은 6행 CSV와 `inputs/july_sales_chart_review.xlsx`를 함께 대조합니다. 이 XLSX는 상품별 비교 실습의 완성 예제를 그대로 복사한 시작 파일입니다.

CSV는 UTF-8입니다. Excel에서 한글이 깨지면 [데이터 → 텍스트/CSV에서]로 UTF-8을 선택합니다. XLSX와 HTML은 다운로드한 뒤 여세요. XLSX 결과는 계산과 차트 구성·미리 보기를 검증한 참고 파일이며, 독자 PC의 Excel 표시도 직접 확인해야 합니다.
