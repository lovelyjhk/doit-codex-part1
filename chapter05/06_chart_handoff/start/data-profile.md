# 매출 데이터 설명

출판 준비용 초안의 학습용 가상 데이터입니다. 실제 업체의 실적이 아닙니다.

- 파일: `sales.csv` / 기간: 2026년 1~12월 / 48행, 7열
- `order_id`: 거래 식별자, `month`: YYYY-MM 월, `region`: 지역, `category`: 카테고리, `channel`: 판매 채널
- `sales`: 거래 매출(원, 정수), `quantity`: 판매 수량(개, 정수)
- 한 행은 거래 1건입니다. 목표·전년 매출 열은 없습니다.
- 빈 셀 0개, 완전히 같은 중복 행 0개입니다. 원본 행을 모두 포함해 합산합니다.
- 연 매출 972,000원, 1월 59,000원, 12월 103,000원입니다.
- 2026년이라는 기간은 연습 데이터의 기준입니다. 실제 오늘 날짜로 바꾸지 않습니다.
