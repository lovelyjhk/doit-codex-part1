# 5장 마무리 문제

새 연습 폴더 안에 `inputs`와 `results` 폴더를 만드세요. 1~4번은 [inputs](inputs/)를 복사하고 5번은 해당 시작 폴더의 파일을 연습 폴더로 복사합니다. 필요한 실행 준비를 코덱스가 먼저 설명하도록 요청하고 확인 뒤 실행하세요. 모든 자료는 가상 데이터입니다.

## 1

- **문제 제목**: 7월 실적 한 문장으로 보고하기 ★
- **문제 내용**: 7월 전체 매출과 6월 대비 증감액·증감률을 계산하여 `results/answer-01.md`에 보고 문장 한 개와 계산 근거를 적으세요. 기준 금액은 6월 매출이며, 7월 8,040,000원·증감액 +310,000원·증감률 +4.0%와 대조하세요. 원본과 자료에 없는 원인은 만들거나 바꾸지 마세요.
- **필요 파일**: [inputs/sales_sample.csv](inputs/sales_sample.csv)
- **모범 답안 파일**: [answer-01.md](../solutions/part2/chapter05/answers/answer-01.md)

복사할 요청문:

```text
inputs/sales_sample.csv를 읽고 7월 전체 매출과 6월 대비 증감액·증감률을 계산해 줘.
results/answer-01.md에 회의 보고 문장 한 개와 계산에 사용한 6월·7월 매출, 증감액, 증감률 공식을 적어 줘. 증감률은 소수점 첫째 자리까지 표시해 줘.
원본은 수정하지 말고, 자료에 없는 매출 원인은 쓰지 마. 실제로 파일을 만들고 저장 위치를 알려 줘.
```

## 2

- **문제 제목**: ‘전체 증가’ 안에 있는 감소 항목 찾기 ★★
- **문제 내용**: `results/answer-02.xlsx`에 데이터·요약·차트 시트를 만드세요. 데이터 6행을 유지하고 상품별 6·7월 매출·증감액·증감률과 전체 행을 표시하세요. 차트는 편집 가능한 묶은 세로 막대형으로 제목, 상품 축, 매출액(원) 축을 표시하고 금액 축은 0부터 시작하세요. A -210,000원, B +520,000원의 합이 전체 +310,000원인지 확인하고 전체 행은 차트에서 제외하세요. A의 감소는 음수와 색으로 표시합니다.
- **필요 파일**: [inputs/sales_sample.csv](inputs/sales_sample.csv)
- **모범 답안 파일**: [answer-02.xlsx](../solutions/part2/chapter05/answers/answer-02.xlsx)

복사할 요청문:

```text
inputs/sales_sample.csv로 results/answer-02.xlsx를 만들어 줘.
데이터 시트에는 원본 6행을, 요약 시트에는 상품별 6월 매출·7월 매출·증감액·증감률과 전체 행을 넣어 줘.
차트 시트에는 상품별 6월·7월 매출을 나란히 보여 주는 엑셀 묶은 세로 막대형 차트를 넣어 줘. 제목은 ‘2026년 6·7월 상품별 매출 비교’, 가로축은 상품, 세로축은 매출액(원)으로 표시해 줘. 금액 축은 0부터 시작하고, 전체 행은 차트에 넣지 마.
A의 감소를 음수 기호와 색으로 구분해 줘. 전체 증감률은 전체 금액으로 계산하고, 상품별 증감액의 합계가 전체 증감액과 일치하는지 확인해 줘. 원본은 보존해 줘.
먼저 만들 파일과 실행 방법을 설명해 줘. 내 승인 뒤에 실행하고 결과 위치를 알려 줘.
```

## 3

- **문제 제목**: 자료 없음과 실적 0 구분하기 ★
- **문제 내용**: 2026년 7월 기록을 나누어 읽고 `results/answer-03.md`에 서울의 기록 수, 확인되는 지역, 서울 매출을 0원으로 써도 되는지와 자료 담당자에게 확인할 문장 한 개를 적으세요. 서울 0행·광주 125행이며 기록 없음과 실제 실적 0을 구분합니다. 담당자·기한은 만들지 마세요.
- **필요 파일**: [inputs/large_sales_sample.csv](inputs/large_sales_sample.csv)
- **모범 답안 파일**: [answer-03.md](../solutions/part2/chapter05/answers/answer-03.md)

복사할 요청문:

```text
inputs/large_sales_sample.csv를 나누어 읽으면서 2026-07-01 이상, 2026-08-01 미만인 기록을 확인해 줘.
서울의 기록 수와 현재 확인되는 지역을 정리하고, 서울 매출을 0원으로 표시해도 되는지 설명해 줘. 자료 담당자에게 확인할 문장도 한 개 써 줘.
결과는 results/answer-03.md에 저장해 줘. 원본은 변경하지 말고, 자료가 없다는 사실을 실제 매출이 없었다는 뜻으로 바꾸지 마. 담당자 이름과 기한도 만들지 마.
```

## 4

- **문제 제목**: 큰 데이터 작은 단위로 처리하기 ★★
- **문제 내용**: CSV를 머리글 제외 최대 100행씩 읽어 `results/answer-04.xlsx`와 `results/chunk-log-100.txt`를 만드세요. XLSX는 추출자료·지역별 확인·검수 시트로 구성하고 2026년 7월 원본 행과 광주·대전·부산·서울의 기록 수·매출·수량·상태를 표시하세요. 전체 1,000행, 선택 125행, 제외 875행, 매출 4,040,000원·수량 996개가 200행 처리 결과와 같아야 합니다. 기록이 없는 지역은 금액·수량을 빈칸으로 두고 확인 필요로 표시합니다. 오류 행은 위치를 알리고 처리 기준 확인 전 중단하며 원본과 이전 결과를 보존하세요.
- **필요 파일**: [inputs/large_sales_sample.csv](inputs/large_sales_sample.csv)
- **모범 답안 파일**: [answer-04.xlsx](../solutions/part2/chapter05/answers/answer-04.xlsx) · [chunk-log-100.txt](../solutions/part2/chapter05/answers/chunk-log-100.txt)

복사할 요청문:

```text
inputs/large_sales_sample.csv를 머리글 제외 최대 100행씩 읽고, 2026-07-01 이상, 2026-08-01 미만인 기록을 추출해 줘. 원본 전체나 처리한 묶음을 계속 메모리에 보관하지 마.
results/answer-04.xlsx의 추출자료 시트에는 선택한 원본 기록을, 지역별 확인 시트에는 광주·대전·부산·서울의 기록 수·매출·수량·확인 상태를 넣어 줘.
기록이 없는 지역은 매출과 수량을 빈칸으로 두고 ‘자료 없음·확인 필요’로 표시해 줘. 기록이 있는 지역도 월 전체 자료인지는 별도로 확인해야 한다고 표시해 줘.
검수 시트에는 원본 파일명, 기간 조건, 전체 처리·선택·제외 행 수, 선택 매출·수량 합계를 넣어 줘. results/chunk-log-100.txt에는 묶음별 처리·선택·제외 행 수와 누적 결과를 남겨 줘.
오류 행이 있으면 임의로 바꾸거나 제외하지 말고 위치와 처리 기준을 먼저 알려 줘. 원본과 기존 결과는 보존해 줘.
먼저 실행 방법을 설명하고, 내 승인 뒤에 필요한 스크립트를 만들고 한 번 실행해 줘. 실제 실행 명령과 결과 파일 위치를 알려 줘.
```
