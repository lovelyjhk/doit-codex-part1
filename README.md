# Do it! Codex 첫째마당 실습 자료 · 초안

첫째마당 「코덱스 시작하기」의 예시 파일, 실습 프롬프트, 마무리 문제와 모범 답안입니다. **출판 준비 중인 초안으로, 내용과 파일 구성은 바뀔 수 있습니다.** Windows와 VS Code의 Codex 확장을 기준으로 설명합니다.

## 시작하기

1. **Code → Download ZIP**으로 내려받은 뒤 압축을 풉니다.
2. [환경 준비](docs/SETUP.md)와 [실습별 폴더 준비](docs/WORK_FOLDERS.md)를 따라 필요한 시작 파일을 복사합니다.
3. 아래에서 실습을 선택하고, 프롬프트를 입력한 뒤 결과를 모범 답안과 비교합니다.
