# Do it! Codex 첫째마당 실습 파일

첫째마당 「코덱스 시작하기」의 예시 자료, 본문 실습 5개, 마무리 문제 5개와 모범 답안입니다. Windows와 VS Code의 Codex 확장을 기준으로 설명합니다. 출판 전 검토용 비공개 저장소입니다.

## 처음 시작하기

1. GitHub에 로그인한 뒤 이 저장소에서 **Code → Download ZIP**을 선택합니다. 내려받은 ZIP 파일을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택합니다.
2. 아래 표에서 실습 안내를 엽니다. 필요한 시작 파일만 별도의 `doit-work` 폴더로 복사하고, VS Code의 **파일 → 폴더 열기**에서 그 폴더를 엽니다.
3. 안내 순서대로 프롬프트를 입력합니다. `@파일명`은 직접 입력한 뒤 표시되는 목록에서 **작업 폴더의 파일**을 선택합니다.
4. 결과를 확인한 뒤 모범 답안을 비교합니다. 답안 파일을 작업 폴더에 미리 복사하면 스스로 결과를 만드는 실습과 섞일 수 있습니다.

파이썬 실행 준비와 오류 해결은 [환경 준비](docs/SETUP.md)를 참고하세요. 저장소를 수정하며 연습하려면 `work` 폴더를 만들어 사용해도 됩니다. **메모리 확인은 저장소 밖의 별도 폴더에서 진행하세요.**
