# Do it! Codex 실습 자료 · 초안

첫째마당과 둘째마당의 실습 자료, 프롬프트, 마무리 문제와 모범 답안입니다. **출판 준비 중인 초안으로 내용과 파일 구성은 바뀔 수 있습니다.** Windows와 VS Code의 Codex 확장을 기준으로 설명합니다.

## 먼저 마당을 선택하세요

1. GitHub의 **Code → Download ZIP**을 선택해 자료를 내려받고 압축을 풉니다.
2. 아래에서 현재 공부하는 마당의 **시작 안내**를 엽니다.
3. 해당 마당의 작업 규칙에 따라 필요한 파일을 연습 위치에 준비합니다. 앞 단계의 결과를 이어 쓰는 실습은 같은 작업 폴더를 유지합니다.

### 첫째마당 · 1~2장 코덱스 시작하기

[시작 안내](part1/README.md) · [작업 규칙](part1/RULES.md) · [파일 찾기](part1/FILES.md) · [프롬프트](part1/PROMPTS.md)

### 둘째마당 · 3~6장 업무에 코덱스 활용하기

[시작 안내](part2/README.md) · [작업 규칙](part2/RULES.md) · [파일 찾기](part2/FILES.md) · [프롬프트](part2/PROMPTS.md)

각 마당의 시작 안내에서 현재 장을 선택하세요. 결과를 만든 뒤 모범 답안을 확인합니다.

## 기존 경로를 유지한 이유

책과 이미 공유한 링크가 깨지지 않도록 실제 자료 폴더 이름은 유지했습니다. 첫째마당 2장 마무리 문제는 `ch03/`, 둘째마당 3장은 `chapter03/`입니다. 이 둘은 [첫째마당](part1/README.md)과 [둘째마당](part2/README.md)의 안내에서 각각 분리해 찾을 수 있습니다.
