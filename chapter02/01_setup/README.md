# [Do it! 실습] VS Code와 코덱스 IDE 확장 설치하기

Windows에서 실습용 폴더를 열고 Codex에 로그인합니다. 시작 파일은 필요하지 않습니다.

1. [환경 준비](../../docs/SETUP.md)에 따라 VS Code와 Python을 준비합니다.
2. VS Code에서 `Ctrl+Shift+X`로 확장 화면을 열고 `Codex`를 검색합니다. 게시자가 **OpenAI**인지 확인하고 설치합니다. [공식 확장 페이지](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt)에서도 확인할 수 있습니다.
3. **파일 → 폴더 열기**에서 직접 만든 빈 `doit-work` 폴더를 엽니다. 폴더 신뢰를 묻는 경우 방금 만든 폴더가 맞는지 확인합니다.
4. Codex 아이콘을 눌러 패널을 엽니다. 아이콘이 없다면 `Ctrl+Shift+P`를 누르고 `Codex: Open Codex Sidebar`를 실행합니다.
5. **ChatGPT로 로그인**을 선택하고 브라우저에서 로그인 절차를 마칩니다. 이 실습에서는 별도 API 키를 만들 필요가 없습니다. 계정에서 사용할 수 있는 Codex 접근 권한과 한도는 로그인 화면의 안내를 확인합니다.
6. 아래 요청을 입력합니다.

```text
현재 열린 작업 폴더가 어디인지 확인하고 알려 줘.
파일을 만들거나 수정하지 마.
```

폴더 경로가 예상과 같고 프롬프트 입력창이 동작하면 준비가 끝났습니다. 설치와 로그인은 독자 PC에서 확인하는 항목이며, 저장소에 완료된 실행 기록을 제공하지 않습니다.
