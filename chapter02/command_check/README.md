# 한 걸음 더 명령어 실행 전에 확인하기

1. [plans.md](plans.md)를 연습 폴더로 복사합니다.
2. 아래 프롬프트로 실행 전 검토만 요청합니다.

```text
@plans.md의 A~D 작업 계획을 검토해 줘.
실제 파일 생성·수정·삭제, 명령 실행, 외부 전송은 하지 마.
작업별로 대상, 예상 변경, 외부 접근, 되돌리는 방법, 위험도, 먼저 확인할 일을 표로 정리해 줘.
목적, 대상, 범위, 복구, 권한과 승인이라는 다섯 가지 질문에도 각각 답해 줘.
확인되지 않은 정보는 [확인 필요]로 표시해 줘.
```

3. 읽기, 새 파일 생성, 삭제, 외부 전송의 차이를 확인합니다. 위험한 계획의 실행 명령을 만드는 실습은 아닙니다.

## 실행 전 다섯 가지 질문

| 확인할 항목 | 스스로 물어볼 질문 |
|---|---|
| 목적 | 왜 실행하며 어떤 결과를 얻으려 하나요? |
| 대상 | 어느 파일과 폴더가 대상인가요? |
| 범위 | 파일 하나인가요, 여러 파일과 하위 폴더까지 포함하나요? |
| 복구 | 실제 백업이나 원본 복사본이 있나요? 되돌릴 수 있나요? |
| 권한과 승인 | 누가 결정할 수 있는 작업이며 어떤 확인이 필요한가요? |

계획에 목적이나 권한이 적혀 있지 않으면 추측해서 채우지 않습니다. 현재 폴더의 실제 위치와 대상 목록을 먼저 확인합니다.
