# 실행 전 검토할 작업 계획

실제 명령을 실행하는 파일이 아니라, 영향 범위를 판단하기 위한 학습 자료입니다.

## A 파일 목록 확인

현재 연습 폴더의 파일 이름과 크기를 읽어 화면에 보여 줍니다. 파일 내용과 외부 사이트에는 접근하지 않습니다.

## B 새 안내 파일 만들기

현재 연습 폴더에 notice.md를 만들고 “실습 준비 완료”라고 씁니다. 같은 이름의 파일이 있으면 멈춥니다. 다른 파일은 바꾸지 않습니다.

## C 폴더 비우기

다운로드 폴더 안의 모든 파일을 삭제하자는 제안입니다. 삭제 대상 목록과 백업 유무는 확인하지 않았습니다.

## D 파일 외부 전송

고객 명단을 외부 서비스에 업로드하자는 제안입니다. 업로드 대상 주소, 수신자와 전송 권한은 확인하지 않았습니다.
