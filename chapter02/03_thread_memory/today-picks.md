# 확장 예시 오늘의 추천 만들기

노래 3곡, 책 분야, 음료를 묶어 매장 안내 문구를 만드는 예시입니다. 지역과 가게 이름을 프롬프트에서 직접 알려 주므로 이 결과만으로 메모리 회상을 확인할 수는 없습니다. 먼저 [짧은 요청으로 메모리 확인](memory.md)을 마친 뒤 활용 예시로 진행하세요.

1. Codex에 아래 문장을 입력합니다. 새로운 스레드에서도 사용할 수 있도록 가게 정보와 문구 조건을 함께 넣었습니다.

```text
서울 종로구의 오늘 날씨를 확인하고, 달빛책방 손님에게 추천할 노래 3곡과 어울리는 책 분야, 음료를 골라 줘.
달빛책방은 서울 인사동에서 카페를 겸한 작은 책방이야.
곡명과 가수는 실제 정보를 확인해 줘.
추천 이유를 짧게 덧붙이고, 다정한 존댓말로 매장에 붙일 ‘오늘의 추천’ 문구도 작성해 줘.
마지막에는 ‘오늘도 좋은 문장 만나세요.’를 붙여 줘.
날씨의 지역·날짜·출처를 적고, 예보인지 관측값인지 구분해 줘.
곡 정보를 확인한 출처도 함께 알려 줘. 확인할 수 없는 내용은 추측하지 마.
지금은 대화창에만 결과를 보여 주고 파일 저장이나 음악 재생은 하지 마.
```

2. 노래가 정확히 3곡인지, 곡명과 가수가 출처와 같은지 확인합니다. 책 분야와 음료는 추천을 위한 창작 제안입니다.
3. 날씨의 날짜와 지역을 대조하고, 매장 안내 문구가 다정한 존댓말인지 읽어 봅니다. 원고의 특정 날짜에 적힌 날씨를 오늘 날씨로 그대로 사용하지 않습니다.
