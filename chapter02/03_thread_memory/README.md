# [Do it! 실습] 스레드와 메모리로 대화 이어 가기

같은 대화에서 파일을 고친 뒤, 새 대화에서 작업 방식이 이어지는지 확인합니다.

## 같은 스레드에서 hello.py 수정하기

1. 앞 실습에서 만든 `hello.py`와 그 스레드를 그대로 사용합니다. 이 실습부터 시작한다면 [시작 파일](start/hello.py)을 별도 작업 폴더에 복사하고, Codex에 `hello.py 내용을 먼저 확인해 줘. 아직 수정하지 마.`라고 요청합니다.
2. 같은 스레드에 다음 문장을 입력합니다.

```text
방금 만든 hello.py를 다음과 같이 수정해 줘.
1. 사용자에게 이름을 입력받는다.
2. 입력받은 이름으로 인사말을 만든다.
3. 인사말 끝에 오늘 날짜를 함께 출력한다.
다른 파일은 수정하지 마.
```

3. VS Code의 **터미널 → 새 터미널**에서 `python hello.py`를 실행합니다.
4. `이름을 입력하세요:` 뒤에 `민지`를 입력하고 Enter를 누릅니다. 다음은 2026-09-05에 실행한 경우의 **출력 형식 예시**입니다.

```text
이름을 입력하세요: 민지
안녕하세요, 민지님! 오늘 날짜는 2026-09-05입니다.
```

첫 줄의 `민지`는 사용자가 입력한 값입니다. 인사말은 입력을 마친 뒤 다음 줄에 출력됩니다. 날짜는 PC의 오늘 날짜에 따라 달라집니다.

5. `준호`로 다시 실행해 이름이 바뀌는지 확인합니다. 입력한 이름과 무관한 인사말이 나오면 다음과 같이 요청합니다.

```text
이름을 입력받은 뒤 그 이름으로 인사말을 출력하도록 고쳐 줘.
입력 안내는 "이름을 입력하세요: "만 보여 주고, 인사말과 오늘 날짜는 다음 줄에 출력해 줘.
```

## 새 스레드에서 메모리 확인하기

6. [달빛책방 메모리 실습](memory.md)을 엽니다. 이 부분은 파일을 고치는 실습과 별도로 진행합니다.
7. 새 스레드에서는 모든 대화와 파일 지시가 그대로 전달된다고 가정하지 않습니다. 실제 파일을 수정할 때는 `@hello.py`처럼 대상을 분명히 지정합니다.

메모리는 이전 대화의 유용한 정보를 다음 작업에서 참고하는 기능이며, 생성·반영이 늦거나 일부 대화가 제외될 수 있습니다. [공식 메모리 안내](https://learn.chatgpt.com/docs/customization/memories)
