# hello 프로젝트

이 프로젝트는 파이썬으로 이름을 입력받고 인사말과 오늘 날짜를 출력하는 예제입니다.

## 실행 방법

VS Code 터미널에서 hello.py가 있는 폴더를 열고 다음 명령을 실행합니다.

```powershell
python hello.py
```

이름을 입력하고 Enter를 누르면 인사말과 날짜가 출력됩니다. 별도 패키지는 필요하지 않습니다.

## 수정 규칙

- 요청한 파일과 기능만 수정합니다.
- 이름 입력 안내와 인사말 출력은 구분합니다.
- 날짜는 실행하는 PC의 오늘 날짜를 사용합니다.

## 앞으로 확인할 일

1. 서로 다른 이름 두 개로 실행해 인사말이 바뀌는지 확인합니다.
2. 출력 날짜가 PC의 오늘 날짜와 일치하는지 확인합니다.
3. 인사말을 수정한 뒤 diff에서 요청한 한 줄만 바뀌었는지 확인합니다.
