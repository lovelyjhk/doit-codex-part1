# [Do it! 실습] @ 파일 태그로 원하는 파일 지정하기

1. [시작 폴더](start/README.md)의 `README.md`와 [hello.py](start/hello.py)를 별도 작업 폴더에 복사해 엽니다. 앞 실습을 이어 한다면 `README.md`만 복사합니다.
2. `README.md`를 열어 프로젝트 목적, 실행 방법, 수정 규칙을 읽습니다. Markdown은 글자와 기호로 제목·목록 등을 표현하는 문서 형식입니다. VS Code에서 `Ctrl+Shift+V`를 누르면 미리 보기를 볼 수 있습니다.
3. Codex 입력창에 `@README`를 입력하고 **작업 폴더의 README.md**를 선택합니다. 입력창에 해당 파일이 연결되었는지 확인합니다.
4. 다음 프롬프트를 입력합니다.

```text
@README.md를 기준으로 이 프로젝트의 목적과 필요한 다음 작업 3가지를 정리해 줘.
지금은 파일을 수정하거나 프로그램을 실행하지 마.
```

5. 결과의 목적과 다음 작업을 원본과 대조합니다. 이름 입력, 오늘 날짜, 변경 검토와 관계없는 기능이 추가되지 않았는지 확인합니다.

파일이 목록에 없다면 파일을 저장하고 폴더를 다시 확인합니다. 태그 기능을 쓸 수 없는 환경에서는 `작업 폴더의 README.md만 읽고...`처럼 경로를 직접 알려 줍니다.
