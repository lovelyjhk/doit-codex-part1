# 1장 본문 예시 프롬프트

이 폴더의 입력 파일을 작업 폴더로 복사한 뒤 사용합니다. 출력 파일이 이미 있으면 덮어쓰지 말고 새 버전 이름을 정하게 하세요.

## 보고서 교정

```text
너는 문서 교정 도우미야.
@report.md의 맞춤법과 어색한 문장만 다듬어 report_edited.md로 저장해 줘.
본문은 존댓말을 사용하고, 원문의 뜻·이름·숫자와 제목 구조를 유지해 줘.
원본과 다른 파일은 수정하지 마.
수정 후 원문과 이름·숫자를 대조하고, 바꾼 표현과 확인 결과를 알려 줘.
```

## 문서 요약

```text
@document.md만 읽고 처음 보고받는 팀장을 위한 summary.md를 새로 만들어 줘.
목적, 핵심 내용, 결정 필요 사항 순서로 10줄 이내로 요약해 줘.
원문에 없는 사실을 만들지 말고 미정 사항은 [확인 필요]로 적어 줘.
원본을 수정하지 말고 요약의 이름과 숫자가 원문과 같은지 확인해 줘.
```

## 월별 매출 요약

```text
너는 매출 자료 검수 도우미야.
@sales_2026.csv만 읽어 sales_summary.md를 만들어 줘.
먼저 컬럼 뜻과 누락값을 확인하고, 다음으로 월별 확인된 금액 합계를 계산해 줘.
amount의 단위는 원이야. 빈 금액을 0으로 확정하거나 임의로 채우지 마.
마지막으로 전체 확인된 금액 합계와 월별 합계가 같은지 검증해 줘.
결과는 월, 확인된 금액 합계, 누락 건수 표와 확인 필요 사항으로 작성해 줘.
원본과 다른 파일은 수정하지 마.
```

## 회의록 정리

```text
너는 PMO 회의록 작성자야.
@meeting.md만 읽고 임원이 빠르게 확인할 meeting_summary.md를 만들어 줘.
결정 사항과 액션 아이템을 나누고, 액션 아이템에는 담당자·해야 할 일·마감일을 표로 적어 줘.
회의록에 없는 사실은 만들지 마. 정해지지 않은 내용은 [확인 필요]로 표시해 줘.
원본은 수정하지 말고, 이름·예산·미정 사항을 원본과 대조한 결과를 알려 줘.
```

## 큰 작업을 단계로 나누기

각 단계의 결과를 읽은 뒤 같은 스레드에 다음 단계를 입력합니다. 이 예제는 슬라이드 구성안을 텍스트로 확인합니다.

```text
@document.md를 읽고 발표에서 다룰 핵심 주제 5개를 뽑아 줘.
원문에 없는 내용은 추가하지 말고 파일은 만들거나 수정하지 마.
```

```text
앞에서 뽑은 주제마다 슬라이드 제목과 설명 2줄을 작성해 줘.
정해지지 않은 내용은 확인 필요로 남겨 줘. 파일은 만들지 마.
```

```text
지역 주민이 궁금해할 순서로 슬라이드 구성안을 재배치하고 이유를 알려 줘.
원문 내용은 바꾸지 말고 파일은 만들지 마.
```
