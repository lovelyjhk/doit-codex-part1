# 01-2 좋은 프롬프트의 6원칙

문서와 데이터를 지정하고, 원하는 결과와 확인 기준을 함께 적는 연습입니다. 이 폴더의 자료는 모두 학습용 가상 자료입니다.

## 본문 기준 파일

- [data.xlsx](data.xlsx): 원고의 금액 합계 예시입니다. `data` 시트의 `amount`는 원 단위이며 빈칸은 누락값입니다.
- [doc/작업용_보고서.docx](doc/작업용_보고서.docx): 원고의 보고서 교정 예시입니다. `doc` 폴더째 복사해 경로를 유지합니다. 문서에는 표, 이미지와 문단 스타일이 있어 서식 보존 여부를 확인할 수 있습니다.

1. `data.xlsx`와 `doc` 폴더를 별도의 작업 폴더에 복사합니다.
2. VS Code에서 작업 폴더를 열고 [프롬프트](prompts.md)의 Excel 합계 또는 Word 보고서 교정 요청을 입력합니다.
3. Excel 결과는 확인된 금액 550,000원과 누락 1건인지 대조합니다. Word 결과는 `있읍니다`, `검토중`만 교정되고 제목·이름·날짜·숫자·표·이미지·서식이 유지됐는지 확인합니다.

## Office 없이 사용하는 대체 자료

Office 파일을 열기 어려운 환경에서는 `report.md`, `document.md`, `meeting.md`, `sales_2026.csv`를 별도의 작업 폴더에 복사합니다. `report.md`는 Word 교정의 텍스트 대체 자료이며, `sales_2026.csv`는 `data.xlsx`와 같은 여섯 거래와 누락값을 담은 CSV 대체 자료입니다. [프롬프트](prompts.md)에서 Markdown 또는 CSV 요청을 사용한 뒤 [예시 결과](../../solutions/ch01/examples/README.md)와 비교합니다.

| 원칙 | 프롬프트에서 확인할 내용 |
|---|---|
| 목표와 맥락 | 입력 파일과 만들 결과를 적습니다. |
| 역할·대상·형식 | 작성자 역할, 읽는 사람, 결과 구성을 적습니다. |
| 단계 나누기 | 읽기, 정리, 검증 순서를 나눕니다. |
| 금지 사항 | 원본 수정, 없는 사실 추가 등을 제한합니다. |
| 불확실성 처리 | 모르는 이름과 날짜는 확인 필요로 남깁니다. |
| 완료 기준 | 합계, 내용 보존 등 확인할 항목을 적습니다. |

Markdown 대체 자료에서는 글의 뜻과 제목·목록 구조만 확인합니다. 표·이미지·글꼴과 문단 서식 보존은 `doc/작업용_보고서.docx` 복사본으로 확인합니다.
