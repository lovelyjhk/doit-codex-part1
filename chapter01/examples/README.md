# 01-2 좋은 프롬프트의 6원칙

문서와 데이터를 지정하고, 원하는 결과와 확인 기준을 함께 적는 연습입니다. 이 폴더의 자료는 학습용 가상 자료입니다. 매출의 `amount`는 원 단위 금액이며, 빈칸은 누락된 값입니다.

1. `report.md`, `document.md`, `meeting.md`, `sales_2026.csv`를 별도의 작업 폴더에 복사합니다.
2. VS Code에서 그 작업 폴더를 열고 [프롬프트](prompts.md) 중 하나를 입력합니다. 원고에서 형식 설명용으로 사용한 `.docx`와 `.xlsx`는 여기서 `.md`와 `.csv`로 바꿨습니다.
3. 생성된 새 파일을 열고 원본의 이름·숫자·미정 항목이 그대로 유지되는지 확인합니다.
4. [예시 결과](../../solutions/ch01/examples/README.md)와 비교합니다.

| 원칙 | 프롬프트에서 확인할 내용 |
|---|---|
| 목표와 맥락 | 입력 파일과 만들 결과를 적습니다. |
| 역할·대상·형식 | 작성자 역할, 읽는 사람, 결과 구성을 적습니다. |
| 단계 나누기 | 읽기, 정리, 검증 순서를 나눕니다. |
| 금지 사항 | 원본 수정, 없는 사실 추가 등을 제한합니다. |
| 불확실성 처리 | 모르는 이름과 날짜는 확인 필요로 남깁니다. |
| 완료 기준 | 합계, 내용 보존 등 확인할 항목을 적습니다. |

문서 교정에서 실제 Word의 표·그림·서식 보존은 별도의 Word 자료가 필요한 확인 항목입니다. 이 Markdown 예제에서는 글의 뜻과 제목·목록 구조를 확인합니다.
