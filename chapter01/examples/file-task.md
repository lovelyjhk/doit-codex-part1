# 01-1 파일을 읽고 실행하는 작업 체험

원고의 `data.xlsx` 금액 합계 예시를 별도 패키지가 필요 없는 CSV로 바꾼 보충 예제입니다. 데이터 파일을 지정하고 코드 작성부터 실행 결과 확인까지 요청합니다.

1. [sales_2026.csv](sales_2026.csv)를 별도 작업 폴더에 복사하고 VS Code로 엽니다.
2. 파이썬이 준비되어 있는지 [환경 준비](../../docs/SETUP.md)에서 확인합니다.
3. 다음 문장을 입력합니다.

```text
@sales_2026.csv를 읽어 amount 열의 확인된 금액 합계를 구하는 sum_sales.py를 만들고 실행해 줘.
파이썬 기본 라이브러리만 사용해 줘. amount는 원 단위 정수야.
빈 금액은 임의로 채우지 말고 누락 건수로 따로 알려 줘.
CSV 원본과 다른 파일은 수정하지 마.
합계와 누락 건수를 출력하고, 원본 데이터와 대조해 결과를 확인해 줘.
```

4. 출력이 다음과 같은지 확인합니다.

```text
확인된 금액 합계: 550,000원
누락된 금액: 1건
```

이는 금액이 적힌 행만 합한 값입니다. 누락된 금액이 있으므로 완전한 매출 총액으로 확정하지 않습니다.
