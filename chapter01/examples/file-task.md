# 01-1 파일을 읽고 실행하는 작업 체험

원고에 나온 [data.xlsx](data.xlsx)를 주 파일로 사용해 코드 작성부터 실행 결과 확인까지 요청합니다. 통합 문서를 읽을 수 없는 환경에서는 [sales_2026.csv](sales_2026.csv)로 같은 값을 연습할 수 있습니다.

## 본문 기준: data.xlsx

1. [data.xlsx](data.xlsx)를 별도 작업 폴더에 복사하고 VS Code로 엽니다.
2. 파이썬이 준비되어 있는지 [환경 준비](../../docs/SETUP.md)에서 확인합니다.
3. 다음 문장을 입력합니다.

```text
@data.xlsx의 data 시트를 읽어 amount 열의 확인된 금액 합계를 구하는 코드를 만들고 실행해 줘.
amount는 원 단위 정수야. 엑셀 원본은 수정하지 마.
빈 금액은 임의로 채우지 말고 누락 건수로 따로 알려 줘.
필요한 라이브러리가 없으면 설치하기 전에 이름과 이유를 알려 줘.
합계와 누락 건수를 출력하고, 원본 데이터와 대조해 결과를 확인해 줘.
```

4. 결과에서 확인된 금액 합계가 550,000원이고 누락된 금액이 1건인지 확인합니다. 누락값이 있으므로 이 값을 완전한 매출 총액으로 확정하지 않습니다.

## 대체 자료: sales_2026.csv

Office 없이 같은 값과 누락 처리를 연습하려면 [sales_2026.csv](sales_2026.csv)를 복사하고 다음 문장을 입력합니다.

```text
@sales_2026.csv를 읽어 amount 열의 확인된 금액 합계를 구하는 sum_sales.py를 만들고 실행해 줘.
파이썬 기본 라이브러리만 사용해 줘. amount는 원 단위 정수야.
빈 금액은 임의로 채우지 말고 누락 건수로 따로 알려 줘.
CSV 원본과 다른 파일은 수정하지 마.
합계와 누락 건수를 출력하고, 원본 데이터와 대조해 결과를 확인해 줘.
```

CSV 모범 코드를 실행하면 다음 결과가 나옵니다.

```text
확인된 금액 합계: 550,000원
누락된 금액: 1건
```
