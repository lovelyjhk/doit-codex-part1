# 1장 마무리 문제 1 부족한 프롬프트 고치기 ★

다음 세 문장을 목표·맥락·제약·완료 조건이 있는 프롬프트로 고쳐 보세요.

1. 보고서 다듬기: “이 보고서를 보기 좋게 정리해 주세요.”
2. 문서 요약하기: “이 자료를 간단하게 요약해 주세요.”
3. 데이터 분석하기: “이 데이터를 분석해서 중요한 내용을 알려 주세요.”

입력 자료는 각각 [report.md](../examples/report.md), [document.md](../examples/document.md), [sales_2026.csv](../examples/sales_2026.csv)입니다.

## 풀이 순서

1. 입력 자료를 읽고 각 요청의 목적과 원하는 결과를 한 문장으로 정합니다.
2. 입력 파일, 출력 파일, 금지 행동, 확인 기준을 포함해 프롬프트 3개를 작성합니다.
3. 실제로 실행해 보려면 입력 파일만 별도 작업 폴더에 복사합니다. 결과를 읽고 다음 기준으로 확인합니다.

- [ ] 바꿀 파일과 만들 파일이 구체적입니다.
- [ ] 원본 보존과 없는 사실을 만들지 말라는 조건이 있습니다.
- [ ] 숫자 대조 또는 누락값 확인 등 완료 기준이 있습니다.
