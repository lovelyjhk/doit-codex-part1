# 1장 마무리 문제 3 반복 규칙 파일 초안 작성 ★★

내 작업 폴더에 적용할 규칙 5줄을 작성하세요.

1. 문서 정리처럼 작업 상황을 하나 정합니다.
2. 원본 보존, 작업 범위, 문체, 불확실한 정보 처리, 결과 검증을 고려해 5줄을 작성합니다.
3. 별도의 연습 폴더에 `AGENTS.md`로 저장합니다.
4. Codex에 다음 문장을 입력해 뜻이 분명하게 전달되는지 확인합니다.

```text
@AGENTS.md를 읽고 적용할 규칙을 요약해 줘.
파일은 수정하지 마.
```
