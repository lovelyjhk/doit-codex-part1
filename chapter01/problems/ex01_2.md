# 1장 마무리 문제 2 내 업무용 템플릿 만들기 ★

문서 요약, 오류 해결, 데이터 분석 중 하나를 골라 재사용할 수 있는 프롬프트를 만드세요.

1. 자주 반복할 작업 하나를 고릅니다.
2. 매번 바뀌는 입력 파일·출력 파일·대상·분량을 대괄호 변수로 표시합니다.
3. 고정해서 지킬 제약과 완료 기준을 적습니다.
4. 변수를 실제 값으로 채운 사용 예를 하나 작성합니다.

확인: 역할, 입력, 출력, 금지 사항, 검수 기준을 빠뜨리지 않았는지 확인하세요.
