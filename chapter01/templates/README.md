# 01-3 실수를 줄이는 프롬프트 관리

1. [AGENTS.template.md](AGENTS.template.md)를 별도의 문서 작업 폴더로 복사하고 이름을 `AGENTS.md`로 바꿉니다. 이 파일은 그 폴더에서 반복해서 지킬 규칙입니다.
2. 실제 업무에 맞게 규칙을 고칩니다. 적용 여부가 불분명한 색상이나 이름을 그대로 두지 않습니다.
3. 그 작업 폴더를 VS Code로 열고 다음 문장을 입력합니다.

```text
@AGENTS.md를 읽고 이 폴더에서 지킬 규칙을 3줄로 요약해 줘.
지금은 파일을 수정하거나 명령을 실행하지 마.
```

4. [작업 전 체크리스트](checklist.md)를 확인하고 [재사용 템플릿](prompts.md)을 실제 파일명으로 채워 사용합니다.

이 규칙 예시는 원본 문서를 보존하는 작업용입니다. `hello.py`를 직접 고치는 2장 실습에는 복사하지 않습니다.
