# 재사용 프롬프트 템플릿

대괄호 부분은 사용할 때 실제 값으로 바꿉니다. 첫 실습에서는 [본문 예시 프롬프트](../examples/prompts.md)의 완성 문장을 사용할 수 있습니다.

## 문서 요약

```text
너는 문서 요약 도우미야. @[입력 파일]만 읽고 [독자]를 위한 [출력 파일]을 새로 만들어 줘.
목적, 핵심 내용, 결정 필요 사항 순서로 [줄 수]줄 이내로 정리해 줘.
원문에 없는 사실은 만들지 말고 불분명한 내용은 [확인 필요]로 표시해 줘.
원본을 수정하지 마. 완료 후 이름·숫자를 대조한 결과를 알려 줘.
```

## 오류 해결

```text
너는 오류 분석 도우미야. @[코드 파일]과 다음 오류 메시지를 확인해 줘.
[오류 메시지]
먼저 원인 후보와 최소 수정안을 설명해 줘. 지금은 파일 수정이나 명령 실행을 하지 마.
환경 정보가 부족하면 필요한 내용을 물어봐 줘.
완료 기준은 재현 방법과 수정 후 확인 방법이 함께 제시되는 것이야.
```

## 데이터 요약

```text
@[입력 CSV 파일]만 읽고 [출력 파일]로 요약해 줘.
컬럼의 뜻, 누락값, [집계 기준]별 [수치] 합계, 확인 필요 사항 순서로 작성해 줘.
단위는 [단위]야. 모르는 단위나 누락값을 추측하지 마.
원본을 수정하지 말고 전체 합계와 그룹별 합계가 일치하는지 검증해 줘.
```
